### 핵심 패턴 분석

**① 모돈 생애주기 = 가장 많이 쓰는 화면 순서**
```
전입 (47K) → 교배 (31K) → 임신사고 (7K) → 분만 (27K) → 양자 → 이유 (18K) → 도폐사 (11K)
```
→ PigOS /record 탭 순서를 이 생애주기에 맞춰야 함

**② 일괄출력(7위)이 보고서 중 1위**
→ 개별 리포트보다 "한 번에 여러 개 뽑기"를 선호
→ PigOS 보고서는 일괄출력 기능이 필수

**③ 종합일보(9위) = 매일 확인하는 화면**
→ 대시보드가 단순 KPI가 아니라 **오늘의 작업 요약**이어야 함
→ "오늘 분만 예정", "이유 예정", "교배 예정" 알림이 핵심
