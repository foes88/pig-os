## 캐나다 양돈 디지털화 동향 (2026-04-27)

> 출처: 캐나다 양돈 AI 도입 사례 리포트

### CloudFarms

| 항목 | 내용 |
|------|------|
| 유형 | Farm Management SaaS (북미) |
| 핵심 기능 | AI로 농장 데이터를 **자체 설정 목표**와 비교 → 성과 패턴 탐지 + 이상 징후 감지 |
| 차별점 | 농장주가 직접 목표값을 입력하고 AI가 그 기준으로 분석 |
| PigOS 대비 | **커버됨** — `default_metric_values` 기준값 비교 + `alerts` Rule Engine으로 동일 기능 구현 예정 |

| 항목 | 내용 |
|------|------|
| 유형 | 데이터 통합 플랫폼 (캐나다) |
| 핵심 기능 | 생산 데이터 + 농장 시스템 데이터를 단일 인터페이스로 통합, **자연어 쿼리**로 소프트웨어와 대화하듯 상호작용 |
| 차별점 | "이번 달 PSY 왜 낮아?" 식으로 질문하면 AI가 농장 데이터 기반으로 즉시 답변 (Pull형 AI) |
| PigOS 대비 | **Gap → 반영 결정** — DevRoadmap Week 7~8에 Layer 3 자연어 Q&A 추가. Claude API로 추가 비용 없이 구현 가능. 7월 Base 베타 포함 검토 |

## 하드웨어 번들 플레이어 (동남아 동시 진입 중)

> 출처: 시장 리포트 / TDX 2026 동향 (2026-05-06)

### Eco-Pork (일본)

| 항목 | 내용 |
|------|------|
| 유형 | 바이오센싱 카메라 + Farm Management 통합 플랫폼 |
| 핵심 기능 | 카메라 기반 돈군 자동 촬영 → AI 번식 관리 (발정 감지·분만 감지) + 행동 이상 탐지 |
| 하드웨어 | 자사 바이오센싱 카메라 필수 (벤더 종속) |
| 진입 지역 | 일본 → 동남아 확장 중 |
| PigOS 대비 | **Gap (번식 AI)** — Eco-Pork은 카메라로 최적 교배 시점 예측·분만 감지 구현. PigOS는 PSY·NPD 계산은 있으나 예측·감지 기능 없음. → **Breeding AI Addon 검토 트리거** (섹션 참조) |

### Big Dutchman (독일)

| 항목 | 내용 |
|------|------|
| 유형 | 사육 장비 + IoT 센서 통합 플랫폼 |
| 핵심 기능 | 급이·환기·온도 자동 제어 + 생산성 모니터링 |
| 하드웨어 | 자사 IoT 장비 번들 (벤더 종속) |
| 진입 지역 | 전 세계 (동남아 포함) |
| PigOS 대비 | **파트너 기회** — 하드웨어 중립 전략으로 Big Dutchman IoT 데이터를 PigOS로 수집 가능. 경쟁자가 아닌 에코시스템 파트너로 포지셔닝 |

### Fancom (네덜란드)

| 항목 | 내용 |
|------|------|
| 유형 | 환경 센서 + 농장 자동화 시스템 |
| 핵심 기능 | 온도·습도·CO₂ 실시간 모니터링 + 자동 환기 제어 |
| 하드웨어 | 자사 환경 센서 번들 |
| 진입 지역 | 유럽 주도 → 동남아 확장 |
| PigOS 대비 | **파트너 기회** — Fancom 환경 데이터 → PigOS TimescaleDB(IoT) 수집 연동 가능 |

## 거시 트렌드 요약

> 글로벌 Farm Management 솔루션이 **버티컬 AI 플랫폼**으로 전환 중

```
기존: 데이터 기록 도구 (입력 → 조회)
현재: AI 분석 추가 (입력 → 조회 → AI 리포트)
다음: 대화형 AI (입력 → AI와 대화 → 실시간 의사결정)
```

PigOS의 4-Layer 구조가 이 전환 방향과 일치:
- Layer 1 Data     → 입력
- Layer 2 Insight  → AI 리포트 (CloudFarms 수준)
- Layer 3 Advisor  → 자연어 Q&A (PLD 수준) ← 7월 베타
- Layer 4 Autopilot → 자동화 (2027+)
