DEBATE 01 #6은 Benchmark API인가 vs Biosecurity Audit인가? GPT 승 · 분류 채택
GPT 주장

Benchmark는 Addon이 아니다. 농가가 앱에서 직접 돈 내는 기능이 아니라 B2B API다.

제품 구조: 농가 Addon ≠ B2B API. 섞으면 세일즈 메시지가 흐려진다.

Biosecurity Audit은 총판이 30초 설명 가능하고 농가가 직접 보고서를 볼 수 있다.

"Insurance Readiness"라는 이름은 농가에게 "데이터 보험사에 팔리나?"라는 의심을 준다.

Claude 수정 수용

GPT의 구조 분리에 동의. Benchmark를 Addon으로 부른 것은 잘못됐다.

단, Benchmark 2026 병행 개발은 유지. 피그플랜 시드 데이터로 콜드스타트 없음. AgentExchange 첫 상품으로 가장 적합.

이름 수정 채택: Biosecurity & Compliance Audit AI — "보험" 전면 제거.

결론: #6 = Biosecurity Audit, Benchmark = PigSignal API #1. 둘 다 2026 병행 개발.

최종 판정
GPT 분류가 맞다. #6 = Biosecurity & Compliance Audit AI. Benchmark = PigSignal API #1로 분리. 단 두 개 모두 2026년에 병행 개발한다. 라벨 차이지 개발 우선순위는 같다.
DEBATE 02 #3 Cost — 완전 무료 Base vs ROI Layer 활용? 절충
GPT 주장

완전 무료만으로 두면 수익화 힘을 잃는다.

#3은 각 Addon의 ROI 증명 엔진으로 써야 한다. FCR 손실액, 폐사 손실액, NPD 손실액을 계산해 유료 Addon 구매를 유도.

Claude 주장

복잡한 회계 입력 → 온보딩 이탈. 독립 과금 SKU는 없애야 한다.

ROI Layer 활용에는 동의. 단 이벤트 데이터에서 자동 파생되어야 하고 별도 입력을 요구하면 안 된다.

최종 판정
절충: 독립 과금 SKU 없음 (Claude 채택). 하지만 각 Addon의 손실액 카드로 활용해 구매 전환을 유도 (GPT 채택). 이벤트 데이터 자동 파생, 별도 회계 입력 없음.
DEBATE 03 #4 Market — 농가용 완전 B2B 전환 vs 대형 농장 가치 유지? 절충
GPT 주장

농가용을 완전히 Base 무료로만 두면 대형 농장 출하 판단 가치를 놓친다.

소농: Base 무료. 대형/출하권 보유 농장: Addon Lite. B2B: PigSignal API.

Claude 주장

소농은 출하 가격 결정권이 없어 유료 구매 의향 없다. "농장은 무료 노드" 전략.

대형 농장 Lite 유지에 일부 동의. 단 별도 SKU보다 Enterprise 플랜에 포함하는 게 맞다.

최종 판정
절충: 소농 = Base 무료. 대형 농장 출하 타이밍 Lite = #4 Addon 또는 Enterprise 포함. B2B = PigSignal API. 3단 구조로 운영.
