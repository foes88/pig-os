## 1. 핵심 결론 (방향 합의)
> 무료 기능으로 데이터 생산비용을 낮추고, 집단 데이터로 사용자에게 더 좋은 결과를 돌려주며, 예측·추천·거래기회를 기업에 판매한다. **원본 데이터가 아니라 분석·예측·추천·거래기회를 판다.** (FBN·Credit Karma·PatientsLikeMe·Waze 공통 공식)

3엔진: PigOS=데이터 생성 엔진(무료/거의 무료) / PigSignal=수익 엔진 / 에이전트 마켓·거래연결=확장 수익 엔진.

## 2. 무료·유료 (→ Entitlement Matrix 승인)
**무료**: "농장 운영에 필요한 아주 기본적인 것 전부" — 기본 번식·사육 루틴, 기본 보고서, 약품·사료 입력(해외 필수), **경영관리 기본(원가−판매=수익)**, 룰 기반 경보(AI 무개입·국가별 룰셋), 익명 벤치마크·타 농장 비교.
**유료 후보**: AI 에이전트 자동실행 / 직원 작업관리 / 질병 조기경보(특화 예측) / 사료효율·FCR / 업그레이드 경영분석 / PigOS Talk / 인사이트(주간·월간) / 상세보고서(⚠️인사이트 중복 지적) / 다농장 통합("도드람은 예외였음") / ERP·센서 연동 / 컨설팅. — "그냥 AI 분석 경보"가 아니라 **무엇에 대한 예측인지 특화 명명** (대표 지시).
**두수**: 대표 제안 "제한하지 않아야 데이터가 생성되고 PigSignal로 간다. 모돈 두수×단가 방식 아님. 매출은 유료 기능에서" → **D-08 등재, 미승인.**
**업셀 UX**: 관련 유료 기능 팝업 → 1주 체험 → 결제수단 등록만·1주 내 해지 미결제 → 월 과금.

## 3. 데이터 권리·약관 (→ Consent Spec)
- 대표: "지금 정리 안 되면 피그플랜 때처럼 또 동의받는 절차 생긴다. 그러지 말아야." 국가별 약관 + 미국 주별 검토, 가입 시점 수령. 무료→유료 전환 시 활용권 유효성 검토.
- 4단계: ①서비스 운영 ②익명·집계 = 기본 동의 / ③AI 학습 ④특정 기업 연구 = **별도 고지·선택 동의**
- 문구: "농장은 원본 권리 유지, 회사는 서비스 제공·개선 위해 처리, 식별 불가하게 익명·집계한 결과를 산업연구·기업 서비스에 활용" — "정확히 약관에 들어가야"
- UI: 볼드 강조 + 별도 동의 + **화면 캡처 보관.** 금지: "무료 대신 데이터는 회사 소유"
- 익명화: Farm-001 치환=가명(판매 불가) / 최소 10~20농장 집계 / dominance 미공개 / "기준을 AI에 주고 데이터셋 생성 가능"

## 4. PigOS 개발
- **밸류 프로포지션 문제 제기**: "한 농장 생산성 증대에만 초점. 농장이 실제 필요한 게 뭔지 파악하고 있는지 계속 의문. 미국 농장주가 원하는 가치를 알아야." (FBN이 준 건 '돈'에 관한 것)
- **경영관리 (제품 P0 제안 → D-09)**: 사료·판매가·도축정산·두당수익·약품·인건비·임대료 → 생산비. "한국은 세금 문제로 27년 못 함. 해외는 원한다. 과감하게 다 넣어라" / 실무 "무조건 있어야 되는 기능". (기술 명칭: lot 귀속 전 "기간 운영비/현금 손익" — 스펙 §6.1)
- **입력 자동화 8채널**: 분만·이유 / 사료주문(기존) / 약품 / 출하 / 직원 작업완료 / 센서 / 음성 / 명세서·사진 OCR. "데이터를 제공해 달라 하지 않는다 — 쓰면 자연히 쌓인다"
- **국가별 KPI**: "미국·브라질은 MSY. 거기다 PSY 얘기하면 안 된다" (사료비 비중 약 70% 언급) / 실무 "국가별 디테일 잡아야" / **대표: 구분 자료 만들어 같이 얘기하는 시간 필요** → 별도 미팅. 날씨 정보 검토(야외 사육).
- **표준화**: "PigSignal 핵심 자산은 원본이 아니라 **국가가 달라도 비교 가능한 양돈 데이터 표준**" — 질병·약품·백신·사료 정규화, 단위, 규모·시설·기후 통일, 이상치·누락. 국가 필드 전부 두고 빈 채로 표준 유지.
- **콜드스타트**: "아이오와 마이클이 가입해 입력하면 비교 버튼에 자동으로 타 농장 비교" + 피그플랜 데이터 국가 포맷 변환 아이디어. ⚠️CTO 검토: A-rule 충돌 소지 → **D-07 대표 결정.** 베트남 신규 초기 입력 부담 → 온보딩 최소 입력(스펙 §11).
- **고객관리 빌트인 (Q-Bridge)**: "빌트인 아니면 미국·베트남·브라질 서비스 불가." 문의 등록→내부 표시→양방향. 다국어 자동 번역(원어→한국어→답변→원어) + **원문·번역 양측 저장.** 실무: 노션 덤프로 틀 잡음. (사후 확정: 단일 Ticket SSOT — INDEX §2)

## 5. PigSignal
- 가치 사다리: 원본 < 정제 < 벤치마크 < 예측 < 실행추천 < **거래연결(최고).** "데이터셋으로 시작하되 결과와 거래를 판다"
- 지적: "현 상품이 구매자 입맛에 맞는지가 핵심. 입맛에 안 맞으면 에이전트도 거들떠 안 본다"
- **Agent 마이크로 상품**: "$6K·$2xK 묶음은 에이전트가 결제 불가. 잘게·싸게·많이. **제목만 보고 AI가 구매 판단**" (예: 경기 모돈 500~1,000두 35농장 분기 평균 PSY). 사람용 묶음은 유지 → 이중 카탈로그.
- 수요처 10세그먼트 니즈 구체화 지시: 사료/약품/백신/금융/보험/육가공/유통/정부·연구/시설/탄소 — 제품소개서에 명확히
- 거래연결 수수료: "A사료 거래되면 수수료" — ⚠️CTO 검토: 특정 농장 타깃·리드는 별도 옵트인 없이 법적 위험 → TRANSACTION_MATCHING 신설, 규제 검토 선행
