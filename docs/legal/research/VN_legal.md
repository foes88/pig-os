# 베트남 법무 리서치 — PigOS 글로벌 (VN 블록)

## 0. 문서 성격 및 검토 기준일

> **본 문서는 변호사 검토 전 초안(내부 리서치 자료)이다.** 법률 자문이 아니며, 베트남 현지 자격 변호사의 검토·확인을 거치기 전에는 어떠한 사업·계약상 의사결정의 최종 근거로 사용할 수 없다. "적법/위법"의 단정 없이 요건·리스크·질의 형태로 서술한다.

- **검토 기준일**: 2026-07-21
- **검토 대상**: 한국 법인 와이즈레이크의 글로벌 양돈 SaaS "PigOS" (서버: 한국) — 무료 Core + 유료 AI, 농장 운영 데이터의 익명·집계 판매(PigSignal), 데이터 사용 목적 6종, 공통 마스터 약관 + 국가별 부속조항 구조
- **핵심 전제**: 베트남 농장 사용자의 계정 정보·농장주/직원 개인정보 및 운영 데이터가 베트남 역외(한국)의 서버로 수집·저장됨 → 수집 시점부터 국외 이전이 상시 발생하는 구조

## 2. 목적 6종별 동의 요건

PDPL상 동의는 원칙적 처리 근거이며, **목적별로 구체적·명시적이어야 하고, 무관한 목적에 대한 동의를 서비스 제공 조건으로 끼워 넣는 것이 제한**된다(Decree 356 세부요건: 서면 또는 검증 가능한 전자적 방식, 침묵·무응답은 동의 아님). 이를 전제로 한 초안 평가:

| # | 목적 | 평가(초안) | 근거·비고 |
|---|---|---|---|
| ① | 서비스 운영 (필수) | **계약 이행 근거로 동의 없이 처리 가능성 있음** — PDPL은 계약상 의무 이행을 동의 예외로 신설. 다만 예외 원용 요건의 세부는 시행령 대조 필요 | Tilleke 분석 (동의 예외에 계약 이행 포함) |
| ② | 익명·집계 통계 (기본) | **개인정보 단계(익명화 처리 행위 자체)는 처리에 해당** → 익명화·통계 목적을 고지 목적에 포함해야 함. 완전히 비식별화된 산출물은 개인정보 범위 밖(§3). "기본 ON(고지 기반)"으로 설계 가능성 있으나, 상업적 재판매 목적이 결합되므로 별도 명시 권장 | PDPL: 비식별 처리 데이터는 개인정보 정의에서 제외 |
| ③ | AI 모델 학습 (선택) | **별도 옵트인 권장(설계안과 일치)**. 목적별 특정 동의 원칙상 ①에 묶을 수 없음. 신법의 AI/신기술 처리 관련 특칙 유무는 **미확인 — 변호사 질의** | 목적 특정성 원칙 |
| ④ | 특정 기업 연구 (선택) | **별도 옵트인 필수 수준** — 제3자 제공+상업 목적. 제공받는 자·목적·항목 특정 필요 | 동의 형식 요건 |
| ⑤ | 거래연결·리드 제공 (선택) | **별도 옵트인 필수 수준 + 매매 금지 조항과의 관계 검토 필요(§3)**. 연락처를 대가 수반하여 제3자에 넘기는 구조는 "개인정보 매매"로 성질결정될 리스크가 가장 큰 목적 | PDPL 매매 금지 (10배 과징금) |
| ⑥ | 외부 AI 처리 (OCR 등, 국외 이전 수반) | 처리위탁 구조면 위탁 법리로 가능성 있으나, **국외 이전 요건(§4: 동의 + TIA)이 중첩** → 국외이전 사실·수령국·수령자 고지 및 동의 항목에 반영 필요 | PDPL 국외이전 조항 + Decree 356 §18 |

**설계 방향 타당성**: PigOS 글로벌의 "선택 목적 옵트인(기본 OFF)" 설계는 베트남 신법의 목적별 명시 동의 원칙과 정합적이며, 한국 피그플랜의 "옵트아웃" 스냅샷을 베트남에 이식하는 것보다 방어력이 높다. **베트남 부속조항은 옵트인 유지 권장.**

## 3. 익명·집계 정보의 법적 지위와 판매 요건 (PigSignal)

### 3.1 익명 데이터의 지위
- PDPL은 **비식별화(de-identified)된 데이터를 개인정보 정의에서 명시적으로 제외**하는 것으로 분석된다 (Tilleke). 따라서 **완전 익명·집계된 산출물의 판매 자체는 PDPL의 개인정보 매매 금지의 직접 적용 대상이 아닐 가능성**이 있다.
- 단, (i) "비식별화"와 "가명처리(pseudonymization)"의 경계, (ii) 재식별 가능성 판단 기준이 법문·시행령에서 어떻게 정의되는지 **원문 확인 필요 — 변호사 질의**. 최소 코호트 5 기준이 베트남에서 "재식별 불가" 수준으로 인정될지는 별도 기술·법률 평가 필요 (소규모 지역·품종 조합에서 특정 농장 식별 리스크).

### 3.2 개인정보 매매 금지 (신법의 핵심 리스크)
- PDPL은 **개인정보의 매매(sale/purchase)를 법률이 달리 정한 경우 외에 엄격히 금지**하며, 위반 시 **불법 수익의 최대 10배 과징금** (PDPL 제8조 관련 — 조항 원문 대조 필요). 예외로 정보주체 동의, 조직 내 공유, 구조조정에 따른 이전, 수탁자 이전, 당국 요구 등이 거론되고, 일부 분석은 "대가를 수반한 이전이라도 일정 요건 하에서는 금지된 매매가 아니다"(제17조 관련)라고 본다.
- **PigSignal에의 함의**:
  - 익명·집계 통계 판매(②) — 개인정보가 아니라면 금지 대상 밖일 가능성. 단 재식별 리스크가 남으면 금지 조항으로 회귀.
  - 리드 제공(⑤) — 식별된 연락처의 유상 제공은 **매매로 성질결정될 리스크가 가장 높음**. "동의 있으면 예외"의 정확한 요건(동의 문언, 대가 고지 필요 여부)을 반드시 확인해야 함 — **변호사 질의**.
- **Data Law 축의 중첩 규제**: Decree 169/2025는 "데이터 분석 서비스", "데이터 중개 서비스"를 규제 서비스로 지정 — 핵심/중요 데이터를 활용한 분석 서비스는 **라이선스 필요**(내부 이용 제외), 데이터 중개 서비스 제공자는 **베트남 국민인 법정대표 + 베트남 내 인프라** 요건이 언급됨. PigSignal(농장 데이터 분석·판매)이 "데이터 분석/중개 서비스"에 해당하는지, 역외 제공 시에도 적용되는지 **미확인 — 변호사 질의 (핵심 쟁점)**.

## 4. 국외 이전(한국 서버) 요건 + 현지화 리스크

### 4.1 PDPL/Decree 356 — 이전영향평가(TIA) 등
- 국외 이전은 허용되나: (i) 유효한 동의(국외이전 사실 포함), (ii) **국외이전 영향평가(TIA) 서류를 처리 개시로부터 60일 내 A05(공안부 사이버보안국)에 제출**, (iii) 변경 시 갱신(6개월 주기 업데이트 언급; 구조조정·신규 사업 시 즉시), (iv) 당국 점검 수인 (Decree 356 제18조 관련).
- 별도로 **DPIA(처리영향평가) 서류도 처리 개시 60일 내 제출** (Decree 356 제19조 관련).
- 국외이전 위반 과징금은 **직전 연도 매출의 최대 5%** 수준으로 확인 — 위반 시 벌칙이 가장 무거운 영역.
- 이전 계약서(이전 목적·정보주체·항목·기간·법적 근거·보호 책임 명시) 요건이 시행령에 규정된 것으로 분석됨 — 표준 문안 필요.

### 4.2 Data Law 60/2024 — 핵심/중요 데이터 분류 리스크
- Decision 20/2025/QD-TTg 기준(미공개 시민 데이터): **중요 데이터** = 기본 데이터 10만~99.9만 명 / 민감 데이터 1만~9.9만 명, **핵심 데이터** = 기본 100만 명+ / 민감 10만 명+ (2025-07-01부터 누적 계산).
- 국외이전: 핵심 데이터는 **사전 영향평가 + MPS(또는 국방부) 서면 승인** 필수, 중요 데이터는 **영향평가 + 이전 15일 전(또는 내) 신고**.
- PigOS 함의: 베트남 가입 농장의 개인 데이터 규모가 위 임계치에 도달하면 한국 서버 이전이 **승인/신고 대상으로 격상**. 초기(수백~수천 농장)에는 임계치 미달 가능성이 높으나, **농장 운영 데이터(비개인 데이터)가 "중요 데이터" 목록(산업 데이터 카테고리)에 별도로 해당하는지 Decision 20 원문 확인 필요 — 변호사 질의**. 축산·농업 생산 데이터가 국가 데이터 목록에 포함될 가능성 배제 불가.
- **입법 리스크**: 2026-10 표결 예정 Law on Data Security 초안은 핵심 데이터 국외이전 전면 금지, 대규모 개인정보 이전의 MPS 사전 승인을 담고 있음 — 통과 시 한국 서버 모델의 규제 부담이 추가 상승.

### 4.3 Decree 53/2022 — 데이터 현지화
- 현지화 대상 데이터(제26조 제1항): 서비스 이용자 개인정보, 이용자 생성 데이터(계정명, 로그인 기록, 이메일, IP 등), 이용자 관계 데이터.
- **외국 기업**은 (i) 10개 지정 업종(통신, 데이터 저장·공유, 전자상거래, 온라인 결제, SNS, 온라인 게임 등)에 해당하고, (ii) A05가 지적한 위반을 시정하지 않거나 사이버보안 조치를 방해하여 **공안부 장관의 서면 결정이 내려진 경우에만** 현지화 및 지사/대표사무소 설치 의무 발생. 이행 기한 12개월, 보관 기간 최소 24개월.
- PigOS 함의: 양돈 SaaS가 10개 업종에 정면으로 해당하는지 불명확("데이터 저장·공유" 광의 해석 리스크). 현재로서는 **조건부·후발적 의무**이므로 한국 서버 운영 자체가 즉시 차단되지는 않는 구조이나, 당국 시정요구에 불응하지 않는 운영 체계가 전제됨.

### 4.4 현지 대리인/지사
- Decree 53상 지사/대표사무소 의무는 위 4.3의 조건 충족 시 발생. PDPL/Decree 356상 역외 사업자의 **상시 현지 대리인 지정 의무가 일반적으로 존재하는지는 확인되지 않음 — 미확인, 변호사 질의**. (DPO는 지정 필수이며 외부 서비스 대체 가능; DPO의 베트남 소재·자격요건 — 베트남 교육기관 훈련 이수 등 초안 요건 — 의 최종 확정 내용 확인 필요.)

## 5. B2B 콜드 아웃리치 적법성 (Decree 91/2020)

- 광고성 이메일·문자·전화는 **사전 명시적 동의(옵트인) 없이 발송 시 "스팸"**으로 정의 — 원칙적으로 콜드 이메일은 위반 소지. Decree 91에 **B2B(법인 대표 메일) 예외가 명시되어 있다는 확인은 하지 못함 — 미확인, 변호사 질의** (수신자가 자연인 계정이면 적용된다고 보는 것이 안전).
- 요건: 광고 표식(라벨링) 및 발신자 식별명 등록(국가 식별 시스템 tendinhdanh.ais.gov.vn), 수신거부(옵트아웃) 즉시 보장, DoNotCall 등록번호 발신 금지, 발송량·시간대 제한.
- 제재: DNC 등록번호 발신 8,000만~1억 VND, 차단 시스템 미이행 1.4억~1.7억 VND 등.
- 역외 발송(한국에서 베트남 수신자에게)에 대한 집행 가능성은 낮더라도 적용 자체는 부정하기 어려움. **권장**: 베트남 시장 초기 아웃리치는 (i) 전시회·명함 등 선행 접점 기반, (ii) 파트너/대리점 경유, (iii) 법인 일반 대표주소 대상 1회 접촉 후 옵트인 전환 구조로 설계하고, 문안·빈도 기준을 부속 정책으로 문서화.

## 6. 철회·삭제권 범위 — "기제공분 소급회수 불가" + "20년 보유"의 방어 가능성

- PDPL은 정보주체의 동의 철회·삭제 요구권을 유지(Decree 13 체계 승계). 철회 시 처리 중단·삭제 의무가 원칙.
- **방어 논리(초안)**:
  1. **익명·집계 산출물은 개인정보가 아님** → 철회·삭제권의 대상 밖이라는 구성이 1차 방어선. "탈퇴 후 통계 데이터 20년 보유"는 보유 대상을 **익명·집계 데이터로 한정**할 때만 방어 가능성이 있음. 원본(식별 가능) 운영 데이터를 20년 보유하는 구성은 목적 달성 후 삭제 원칙과 충돌 소지 — **베트남 부속조항에서는 '탈퇴 시 개인정보 삭제 + 익명 집계본만 존속'으로 문언 분리 권장**.
  2. **기제공분 소급회수 불가**: 이미 제3자에게 판매·제공된 익명 집계 산출물은 개인정보가 아니므로 회수 의무가 없다는 구성. 다만 익명성이 부정되면(재식별) 소급 문제 발생 — 코호트 기준의 기술적 방어 문서화 필요.
  3. 철회의 **장래효**(철회 전 적법 처리에 불영향)가 PDPL에 명문화되어 있는지 **원문 확인 필요 — 변호사 질의**. Decree 13 체계에서는 철회 전 처리의 적법성이 유지되는 구조였으나 신법 문언 재확인 필요.
- **리스크**: 베트남에 20년이라는 구체적 보유기간을 정당화할 법정 근거는 확인되지 않음. "보유기간은 목적 달성에 필요한 기간" 원칙 하에 20년의 합리성 소명 필요 — 산업 통계의 장기 시계열 필요성 논거를 부속조항·고지문에 명시할 것.

## 7. 인테그레이터(대기업 계열) 소속 농장 데이터의 특수 이슈

- 베트남 양돈업은 인테그레이터(CP Vietnam, Dabaco, Masan, GreenFeed, Japfa 등) 계약사육 비중이 높음. 계약사육 구조에서 **운영 데이터의 계약상 권리(소유·이용권)가 농장이 아닌 인테그레이터에 유보**되어 있을 가능성이 큼.
- 쟁점:
  1. 농장이 PigOS에 입력하는 데이터가 인테그레이터와의 사육위탁계약상 **비밀유지·데이터 귀속 조항 위반**이 될 수 있음 → 와이즈레이크가 제3자 계약위반 유인 책임(민사)에 노출될 가능성 — 계약 실태 확인 필요.
  2. 개인정보 축에서는 농장주 개인 데이터의 동의 주체는 농장주이지만, **운영 데이터(비개인)의 이용권은 계약 문제** → 약관에 "입력 데이터에 대한 적법한 권리 보유 및 제3자 권리 비침해" 진술보증 + 면책 조항 필수.
  3. 인테그레이터 소속 농장 데이터가 집계에 포함되면, 코호트 5 기준으로도 **특정 인테그레이터의 사업 정보가 추론**될 수 있음(영업비밀 침해 주장 리스크) — 인테그레이터 단위 필터링/제외 옵션 검토.
  4. 반대로 인테그레이터를 PigSignal 구매 고객으로 두는 경우 이해상충 관리(자사 계약농장 데이터 열람 차단) 설계 필요.
- **권장**: 베트남 부속조항에 (i) 데이터 권리 진술보증, (ii) 인테그레이터 소속 여부 신고 필드, (iii) 인테그레이터와의 별도 3자 데이터 계약 템플릿 옵션을 반영. 계약 실무는 **현지 변호사 질의 필수**.

## 8. 변호사 확인 필수 질의 목록

1. **PDPL 조항 원문 대조**: 본 초안이 인용한 매매 금지·국외이전·동의 예외의 정확한 조문 번호와 문언 (영문 요약 간 조항 번호 불일치 존재).
2. **Decree 13 → PDPL/Decree 356 경과규정**: 구법 하 제출된 DPIA/TIA의 승계 여부, 재제출 필요성.
3. **비식별화 기준**: PDPL/Decree 356상 익명 vs 가명의 정의·재식별 판단 기준, 최소 코호트 5가 "비식별" 인정에 충분한지.
4. **매매 금지 예외의 요건**: 정보주체 동의로 유상 제공(⑤ 리드 모델)이 허용되는지, 동의 문언에 대가성 명시가 필요한지, 제17조 "금지된 매매가 아닌 유상 이전"의 정확한 범위.
5. **Decree 169/2025 데이터 서비스 규제**: PigSignal이 "데이터 분석 서비스"/"데이터 중개 서비스"에 해당하는지, 역외 사업자에게도 라이선스·현지 법정대표·현지 인프라 요건이 적용되는지.
6. **Decision 20/2025 데이터 목록**: 축산·농업 생산 데이터가 "중요/핵심 데이터" 카테고리에 포함되는지, 개인 데이터 임계치(10만/100만 명) 계산 방식.
7. **TIA/DPIA 실무**: 역외 사업자의 제출 절차(대리 제출 가능 여부), 60일 기산점, 6개월 갱신 주기의 정확한 근거, 베트남어 서류 요건, A05 실사 대응.
8. **외국 사업자의 상시 현지 대리인 의무** 존부(PDPL/Decree 356), DPO의 소재지·자격 요건(베트남 기관 훈련 이수 요건 확정 여부), 외부 DPO 서비스 이용 가능성.
9. **SME/스타트업 5년 유예**: 외국기업(와이즈레이크)이 원용 가능한지, "10만 명 이상" 제외 기준의 계산 방식.
10. **철회의 장래효**: 철회 전 적법 처리 및 기생성 익명 산출물에 대한 소급 효과 부존재의 명문 근거.
11. **보유기간 20년**: 베트남에서 장기 보유(익명화 후 존속 구조 포함)에 대한 규제·가이드라인 존부.
12. **Decree 91/2020의 B2B 및 역외 적용**: 법인 이메일 대상 콜드 아웃리치의 실무상 허용 범위, 발신자 식별명 등록이 역외 발신자에게 요구되는지.
13. **인테그레이터 계약 실태**: 주요 인테그레이터 사육위탁계약의 데이터 귀속·비밀유지 조항 관행, 3자 계약 필요성.
14. **Law on Data Security 초안(2026-10 표결)**: 통과 가능성·시행 시기, 대규모 개인정보 국외이전 MPS 사전 승인 조항이 PigOS에 미치는 영향.
15. **약관 준거법·분쟁해결**: 베트남 소비자·전자상거래법상 준거법을 한국법으로 지정하는 부속조항의 유효 범위.
