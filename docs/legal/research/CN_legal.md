# PigOS 중국 진출 법률 리서치 — 데이터 3법 체계 분석 (초안)

> **문서 성격**: 본 문서는 **변호사 검토 전 내부 리서치 초안**이다. 법률 자문이 아니며, 모든 결론은 중국 자격 변호사(및 데이터 규제 전문 로펌)의 검토·확인을 거치기 전까지 의사결정의 최종 근거로 사용할 수 없다. "적법/위법"의 단정을 피하고 요건·리스크·질의 형태로 서술한다.
>
> **검토 기준일**: 2026-07-21 (웹 확인 기준). 중국 데이터 규제는 하위 규정·Q&A가 수시로 갱신되므로 실제 진입 시점에 재확인 필요.

## 0. 전제 사실 (분석 대상 사업 구조)

- 한국 법인 와이즈레이크가 글로벌 양돈 SaaS "PigOS" 운영, **서버는 한국 소재**.
- 무료 Core + 유료 AI. 농장 운영 데이터를 익명·집계하여 산업 인텔리전스(PigSignal)로 기업에 유상 판매.
- 데이터 사용 목적 6종: ①서비스 운영(필수) ②익명·집계 통계(기본) ③AI 모델 학습(선택) ④특정 기업 연구(선택) ⑤거래연결·리드 제공(선택) ⑥외부 AI 처리(OCR 등, 국외 이전 수반).
- 약관: 공통 마스터 + 국가별 부속조항. 글로벌은 선택 목적 옵트인(기본 OFF) 설계 예정.
- 중국 특성: 초대형 기업(牧原 Muyuan, 温氏 Wens 등) 중심 + 정부의 생돈(生猪) 생산 데이터 관리 강함. 아프리카돼지열병(ASF) 이후 돼지 생산·질병 데이터의 국가적 민감성 높음.

## 2. 농장 운영 데이터의 분류 — "중요 데이터(重要数据)" 해당성 (최대 리스크 섹션)

### 2.1 제도 구조
- DSL 제21조: 국가가 데이터 분류·등급 보호제를 시행하고, **각 지역·부문이 자기 분야의 중요 데이터 구체 목록을 작성**한다. 목록은 대체로 비공개이며 해당 처리자에게 통지되는 방식.
- GB/T 43697-2024(2024-10-01 시행)가 식별 기준 제공: "특정 분야·군체·지역에 관한 데이터로서 유출·변조·훼손 시 국가안보, 경제 운행, 사회 안정, 공공 건강·안전을 직접 위해할 수 있는 데이터". 식별 요소로 분야·군체·지역·**정밀도·규모·심도·커버리지** 등을 제시. (출처: https://www.china-briefing.com/news/china-data-classification-standards-important-data/ )
- 완화 요소: 네트워크데이터안전관리조례 및 CAC Q&A는 **"주관부처로부터 중요 데이터로 통지(告知·公布)받지 않은 한 중요 데이터로 취급할 의무가 없다"**는 취지의 실무 기준을 확인 (2024-03 규정 제2조 취지 동일). 다만 통지 수령 시 **2개월 내 안전평가 신청** 의무 — 유예기간 없음 (CAC 2025-10-31 Q&A, 출처: https://www.arnoldporter.com/en/perspectives/advisories/2025/11/china-issues-clarifications-cross-border-data-transfer-rules ).

### 2.2 양돈 데이터의 해당 가능성 평가
PigOS가 수집하는 농장 운영 데이터(모돈 두수, 출하량, 폐사율, 질병 발생, 사료·약품 사용 등)는 개별 농장 단위로는 기업 데이터이나, 다음 이유로 **집적 시 중요 데이터 판정 가능성이 상당**하다:

1. **식량 안보 직결**: 생돈은 중국 CPI·식량 안보의 핵심 품목. 국가는 「디지털 농업농촌 발전규획」에서 양돈장 데이터의 국가 직보 체계("一场一码、一畜一标" 동태 데이터베이스)를 명시 — 즉 생돈 생산 데이터를 국가 관리 대상 데이터로 보는 정책 방향이 문서로 확인됨 (출처: https://faolex.fao.org/docs/pdf/chn193207C.pdf ).
2. **규모·커버리지 기준**: GB/T 43697-2024의 식별 요소(규모·정밀도·커버리지)상, 牧原·温氏급 초대형 기업 또는 다수 농장의 생산·질병 데이터를 한 플랫폼이 집적하면 "특정 산업의 경제 운행 상황을 반영하는 데이터"로 포섭될 여지가 큼. 개별 농장 가입 단계에서는 낮아도 **사업이 성공할수록 리스크가 커지는 역설적 구조**.
3. **질병(疫情) 데이터의 특수성**: ASF 이후 동물 질병 발생 정보는 사실상 국가 통제 정보. **동물방역법상 동물 疫情은 농업농촌부(또는 수권받은 성급 부처)만 공표할 수 있고 기타 단위·개인의 발표가 금지**된다 (출처: https://www.gov.cn/xinwen/2021-01/23/content_5582023.htm ). PigSignal이 "중국 내 질병 발생 동향" 류의 인텔리전스를 집계·판매하는 행위는 중요 데이터 여부와 **별개로** 이 조항과 정면 충돌할 소지가 있다 — 익명·집계 처리로도 해소되지 않는 리스크.
4. **통계법 인접 리스크**: 전국·지역 단위 생돈 생산 통계의 민간 편제·유상 제공이 통계 관련 규제(涉外 통계조사 허가 등)에 저촉되는지 — **미확인 — 변호사 질의**.

### 2.3 소결 (초안 의견)
- 농업 분야의 **확정·공표된 중요 데이터 목록은 미확인** (§1 참조). 형식적으로는 "통지받기 전까지 중요 데이터 아님" 원칙에 기댈 수 있으나, 양돈 생산·질병 데이터는 통지 대상으로 지정될 개연성이 높은 범주이고, 지정 시 2개월 내 안전평가(국외이전 사실상 차단 가능)라는 급격한 체제 전환을 강요받는다.
- **리스크 등급: HIGH** — 사업 모델의 핵심(데이터 집적→국외 서버→인텔리전스 판매)이 모두 중요 데이터 규제와 충돌 가능. §8의 진입 구조 승격 권고로 연결.

## 3. 목적 6종별 동의 요건 (PIPL 별도동의 单独同意 지점)

전제: 농장 데이터 중 개인정보에 해당하는 부분(농장주·직원 계정정보, 개인사업자 농장의 경영 데이터 등)에 PIPL 적용. 법인 농장의 순수 경영 데이터는 개인정보가 아니나 DSL·조례(중요 데이터·네트워크 데이터)의 적용은 받는다. PIPL은 GDPR과 달리 '정당한 이익' 처리 근거가 없어 **동의 의존도가 높다**.

| 목적 | PIPL상 처리 근거 | 별도동의(单独同意) 필요 여부 | 비고 |
|---|---|---|---|
| ① 서비스 운영 (필수) | 계약 이행(제13조 2호) | 불요 | 다만 한국 서버 처리 = 국외이전이므로 **제39조 별도동의 필요** (아래 공통) |
| ② 익명·집계 통계 (기본) | 익명화 완성 전 처리 단계는 동의 필요 논점 | 익명화 '처리행위' 자체의 근거 고지 필요 | 완전 익명화 후에는 PIPL 밖(§4). "기본 ON" 설계의 방어 논리 필요 — **변호사 질의** |
| ③ AI 모델 학습 (선택) | 동의(옵트인) | 목적 명시 동의 필요. 국외 서버 학습 시 제39조 별도동의 중첩 | 글로벌 설계(기본 OFF)와 정합 |
| ④ 특정 기업 연구 (선택) | 동의 + **제3자 제공 시 별도동의(제23조)** | **필요** | 제공받는 자·목적·유형 개별 고지 |
| ⑤ 거래연결·리드 제공 (선택) | 동의 + 제23조 별도동의 | **필요** | 개인 연락처 제공 시 전형적 별도동의 사안 |
| ⑥ 외부 AI 처리 (OCR 등, 국외이전) | 위탁(제21조) + **국외이전 별도동의(제39조)** | **필요** | 수령자 명칭·연락처·처리 목적·방식·정보 유형·권리행사 방법 고지 |

**공통**: 서버가 한국인 이상 ①~⑥ 전부에 국외이전이 내재하므로, 동의 화면에서 **제39조 별도동의**(수령자 정보 포함 상세 고지)가 가입 시점에 필요하다. 2024-03 완화 규정의 면제사유에 해당하더라도 **별도동의 등 PIPL상 의무는 면제되지 않음** (출처: https://privacymatters.dlapiper.com/2024/03/china-cross-border-data-transfer-requirements-exemptions-now-available/ ). 또한 CAC 2025-10 Q&A는 SCC 신고 서류에 **역외 제3자 재제공(onward transfer) 명시**를 요구 — 목적 ⑥(외부 AI)과 ④⑤(기업 제공)를 신고서에 반영해야 한다.

## 4. 익명·집계 정보의 법적 지위와 판매 요건

### 4.1 익명화 기준 (PIPL 제73조)
- 정의: "개인정보를 처리하여 **특정 자연인을 식별할 수 없고 복원(复原)할 수 없게** 하는 과정". 익명화된 정보는 개인정보가 아니어서 PIPL 밖 (출처: https://www.chinafy.com/blog/what-is-data-anonymization-and-de-identification-in-china ).
- 거식별화(去标识化)와 구별: 추가 정보로 재식별 가능한 상태는 여전히 개인정보. PigSignal의 "익명·집계"가 어느 쪽인지가 관건. **원본 보유 사업자가 스스로 '복원 불가'를 주장하는 구조의 인정 기준에 관한 공식 지침은 미확인 — 변호사 질의** (최소 코호트 5가 중국 기준으로 충분한지 포함).

### 4.2 익명이어도 남는 규제 (핵심)
1. **중요 데이터 규제는 익명화로 회피 불가**: 중요 데이터는 개인정보 여부와 무관한 개념. 집계 통계일수록 오히려 "산업 운행 상황 반영" 성격이 강해져 중요 데이터성이 **증가**할 수 있다 (§2).
2. **동물 疫情 공표 금지** (§2.2-3): 질병 관련 인텔리전스 상품은 익명·집계 여부와 무관하게 동물방역법 리스크.
3. **데이터 거래 규제 (DSL)**: DSL 제33조는 **데이터 거래 중개기구**에 제공자 신원·출처 확인 의무 부과. 현재 데이터 상품 거래를 데이터거래소(上海数据交易所 등) 경유로 유도하는 정책 흐름이 있으나, **거래소 경유가 법적 의무인지 여부는 미확인 — 변호사 질의** (지방 데이터조례별 상이 가능). PigSignal을 중국 기업에 판매하는 행위가 "데이터 거래"로 성격 규정될 경우의 등록·신고 요건 확인 필요.
4. **조례상 제3자 제공 계약 의무**: 네트워크 데이터 제공 시 목적·방식·범위·보안 의무를 계약으로 특정해야 함 (출처: https://www.china-briefing.com/news/china-issues-new-regulations-on-network-data-security-management-effective-january-1-2025/ ).

### 4.3 소결
"익명화했으니 자유 판매"는 중국에서 성립하지 않는다. (i) 익명화 완성도, (ii) 중요 데이터성, (iii) 疫情 정보 해당성, (iv) 데이터 거래 규제의 4중 검토가 필요. 특히 질병 지표는 중국판 PigSignal에서 **상품 구성 자체를 재검토**(제외 또는 정부 협력 모델)할 필요.

## 5. 국외 이전·현지화 — 한국 서버 구조 성립 가능성

### 5.1 3경로 + 면제 (2024-03 규정 반영, 출처: https://privacymatters.dlapiper.com/2024/03/china-cross-border-data-transfer-requirements-exemptions-now-available/ )
| 경로/면제 | 요건 (연간 기준) |
|---|---|
| **면제** | 비민감 개인정보 **10만 명 미만** 이전, 계약 이행 필요, HR 관리, 긴급상황, 역외 수집 데이터의 재반입 등 |
| SCC 신고 (표준계약) | 비민감 10만~100만 명 또는 민감정보 1만 명 미만 |
| 인증 | SCC와 동일 구간의 대체 경로 |
| **CAC 안전평가 (강제)** | **중요 데이터 이전(수량 무관)**, CIIO(수량 무관), 비민감 100만 명 이상, 민감 1만 명 이상 |

### 5.2 PigOS 적용 (시나리오)
- **낙관 시나리오**: 개인정보 주체 수(농장주·직원)는 초기 10만 명 미만일 것 → 개인정보 국외이전은 **면제 구간**에 들 가능성. 단 별도동의·PIPIA(개인정보보호영향평가)·고지 의무는 존속. 법인 농장의 비개인 경영 데이터는 중요 데이터가 아닌 한 국외이전 제한 없음(일반 데이터 자유 이전 원칙).
- **비관 시나리오 (개연성 상당)**: 축적 데이터가 중요 데이터로 통지·판정되는 순간 **수량 무관 CAC 안전평가 강제**. 안전평가는 중요 데이터의 국외 반출을 불허하는 결론이 날 수 있고(승인율·심사 기준 비공개), 통지 후 2개월 내 신청 의무. 이 경우 **한국 서버 단일 구조는 지속 불가** — 중국 내 인프라(현지화) + 국내외 데이터 분리 아키텍처로 전환 강제.
- FTZ 네거티브리스트 경로(리스트 외 데이터 자유 이전)는 **중국 내 FTZ 등록 법인**을 전제로 하므로 역외 직접 서비스 모델에는 적용 불가. 현지 법인 설립 시나리오에서는 톈진(농업 관련 항목 포함 여부 확인 필요)·베이징·상하이 리스트 검토 가치 있음 — **해당 FTZ 리스트의 농업 데이터 항목 포함 여부 미확인 — 변호사 질의** (출처: https://www.china-briefing.com/news/china-data-export-policy-ftzs/ ).

### 5.3 소결
한국 서버 구조는 **"중요 데이터 비지정 + 개인정보 소규모" 전제에서만 조건부 성립**한다. 설계상 (i) 중국 데이터의 논리적 분리, (ii) 중요 데이터 지정 시 90일 내 현지화 전환이 가능한 아키텍처(중국 리전 콜드 스탠바이), (iii) 질병 필드의 수집 최소화를 사전에 반영할 것을 권고. **리스크 등급: HIGH**.

## 6. B2B 콜드 아웃리치 적법성

- 중국은 전자적 직접 마케팅에 **사전 동의(옵트인)** 를 요구한다. 근거: 互联网电子邮件服务管理办法(2006) — 상업성 전자우편은 수신자의 명시적 동의 없이 발송 금지, 제목에 "广告/AD" 표기 의무; PIPL — 전자 주소 수집 시 또는 이후의 명시적 동의 필요; 광고법 제43조 — 동의·요청 없이 전자적 광고 발송 금지, 발신자 신원·수신거부 방법 표시 의무 (출처: https://www.dlapiperdataprotection.com/index.html?t=electronic-marketing&c=CN ; https://uk.practicallaw.thomsonreuters.com/w-039-3304 ).
- **B2B 예외 없음**: 확인한 출처들은 B2B/B2C를 구분하지 않는다. 법인 대표메일(info@)이 아닌 임직원 개인 업무 메일은 개인정보이기도 하다. 따라서 **콜드 이메일(사전 동의 없는 발송)은 요건 위반 소지** — 집행 강도와 무관하게 대기업(牧原·温氏 등) 대상 아웃리치에서 브랜드·규제 리스크.
- 대안: 전시회·협회 경유 명함 기반 후속 연락(동의 확보 시점 기록), WeChat 공식계정·위챗워크 기반 인바운드, 현지 파트너의 기존 거래관계 활용. **리스크 등급: MED** (민사·행정 제재 가능성은 중간이나 회피 용이).

## 7. 철회·삭제권 범위 — "기제공분 소급회수 불가" + "20년 보유"의 방어 가능성

- PIPL 제15조(동의 철회 — 철회 전 처리의 효력에는 영향 없음), 제47조(삭제권 — 목적 달성·동의 철회 등 시 삭제 의무).
- **방어 가능한 부분**: "기제공분 소급회수 불가"는 PIPL 제15조 2문("철회는 철회 전에 이미 이루어진 처리의 효력에 영향을 미치지 않는다")과 정합적으로 구성 가능. 또한 **완전 익명화가 인정되면** 익명 통계는 개인정보가 아니므로 삭제권 대상 밖이라는 논리 성립 여지.
- **취약한 부분**: (i) "탈퇴 후 통계 데이터 20년 보유"를 **개인정보 상태로** 보유한다면 제47조 및 최소 보존기간 원칙(제19조)과 충돌 — 탈퇴 시점에 즉시 익명화 완료하는 프로세스로 재구성해야 방어 가능. (ii) 익명화 완성도가 부정되면(§4.1) 20년 보유·소급회수 불가 조항 전체가 무너짐. (iii) 법인 농장 데이터라도 중요 데이터로 지정되면 보유·처리 자체에 별도 의무 부과.
- 중국 부속조항 설계 제안(초안): "탈퇴 시 개인정보는 삭제하고, 이미 생성된 익명·집계 통계(복원 불가)는 개인정보가 아니므로 존속한다"로 서술 구조 변경 — '20년'이라는 기간 명시는 개인정보 보유로 오인될 소지가 있어 재고 권고. **리스크 등급: MED**.

## 8. 진입 구조 옵션 비교 + 승격 권고

| 옵션 | 구조 | 장점 | 규제 리스크 |
|---|---|---|---|
| A. 역외 직접 서비스 | 한국 법인이 중국 농장에 직접 SaaS 제공 (PIPL 제3조 2항 역외 적용) | 투자 최소, 데이터 통제권 유지 | **PIPL 제53조 현지 전문기구/대표 지정 + 명칭·연락처를 당국에 보고** 의무 (출처: https://www.klgates.com/What-is-Required-Under-The-PIPL-A-PRC-Based-Representative-or-a-Personal-Information-Protection-Officer-1-7-2022 ). 중국 내 서버 없이는 ICP 불요이나 **방화벽 차단·접속 품질 리스크**, 위안화 결제·세무 문제, 중요 데이터 지정 시 대응 수단 부재 |
| B. 현지 법인 (WFOE) | 중국 법인 설립, 중국 리전 서버 운영 | ICP 비안/허가 취득 가능(상업 SaaS는 증치전신업무 허가 필요 — 외자 지분 제한과 2024~ FTZ 개방 시범의 적용 여부 **미확인 — 변호사 질의**), FTZ 네거티브리스트 활용 가능, 중요 데이터 지정 시에도 사업 지속 | 설립·운영 비용, 데이터의 중국 내 고착(글로벌 통합 분석 제약), 당국 접근권 노출 |
| C. 합작(JV)/라이선스 | 현지 파트너(축산 그룹·수의 플랫폼·국유 데이터 기업)에 소프트웨어 라이선스, 데이터는 파트너가 처리자 | 규제 의무 대부분 파트너에 이전, 疫情·중요 데이터 리스크 절연, 정부 관계 활용 | 수익 배분·통제권 상실, PigSignal 글로벌 데이터풀에 중국 데이터 편입 불가(또는 집계 지표만 수입), 파트너 종속 |

### 승격 권고 (명시)
§2(중요 데이터)·§5(국외이전)가 **HIGH**로 평가되므로, 사전 합의된 기준에 따라 **"중국 시장 진입 구조 자체(직접/합작/라이선스)"를 변호사 질의로 승격한다**. 초안 의견으로는, 중요 데이터 지정 리스크와 동물방역법상 疫情 공표 금지를 고려할 때 **옵션 A 단독(한국 서버 + 역외 직접 + PigSignal 판매)은 권장하기 어려우며**, 최소한 "옵션 A로 소규모 검증 → 임계 규모 전 옵션 B/C 전환" 또는 처음부터 옵션 C(라이선스)로 데이터 처리자 지위를 현지에 두는 구조를 변호사와 검토할 것을 권고한다. 중국 데이터의 글로벌 PigSignal 편입은 별도 타당성 검토 전까지 로드맵에서 보류 권고.

## 9. 변호사 확인 필수 질의 목록

1. **[중요 데이터]** 농업농촌부 또는 성급 정부가 농업(축산/생돈) 분야 중요 데이터 목록을 제정·통지한 사례가 있는가? 양돈 생산량·폐사율·질병 발생 데이터가 목록(안)에 포함되는가? 비공개 목록의 실무 확인 방법은?
2. **[중요 데이터]** 플랫폼 사업자가 다수 농장 데이터를 집적하는 경우, 개별 데이터가 아닌 **집적물** 기준으로 중요 데이터 판정이 이루어진 선례·지침이 있는가? "통지 전까지 비(非)중요" 원칙에 의존한 사업 설계의 실무적 안전성은?
3. **[疫情]** 동물방역법상 疫情 공표 금지 조항이 (i) 익명·집계된 질병 발생률 지표의 **유상 B2B 제공**, (ii) 고객 농장 자신의 데이터 대시보드 표시에 각각 적용되는가? 위반 시 제재 수위는?
4. **[통계]** 외국 기업이 중국 내 산업 데이터를 수집·집계하여 판매하는 행위가 통계법·涉外조사 허가 규제 대상인가?
5. **[국외이전]** 개인정보 주체 10만 명 미만 면제 구간에서, 법인 농장의 비개인 경영 데이터의 한국 이전에 현행 별도 제한이 있는가? (일반 데이터 자유 이전 원칙의 확인)
6. **[익명화]** PIPL 제73조 익명화의 인정 기준 — 원본 데이터를 계속 보유한 처리자의 집계 통계가 '복원 불가'로 인정되는가? 최소 코호트 5는 충분한가? 참조할 국가표준·지침은?
7. **[데이터 거래]** PigSignal 유상 판매가 DSL·지방 데이터조례상 "데이터 거래"에 해당하여 데이터거래소 경유·등록·신고 의무가 있는가? (상하이·선전 등 지방조례 차이 포함)
8. **[역외 적용]** PIPL 제53조 전문기구/대표 지정의 실무(보고 대상 기관·양식·시기)와, 네트워크데이터안전관리조례상 역외 처리자 의무의 중첩 범위는?
9. **[진입 구조]** 외국계 SaaS의 증치전신업무(B25 등) 허가 요건과 2024년 이후 FTZ 외자 개방 시범이 양돈 SaaS에 적용 가능한가? ICP 비안만으로 가능한 구조가 있는가?
