# TERMS_DISPLAY_SPEC v1.0
## 가입·이용 플로우별 약관 표시 규칙 (국가/주 분기) — 개발 구현 스펙

> 성격: 변호사 확정 전 초안(문서 내용은 drafts/ 확정본으로 교체 전제). 동의 수집·기록의 상세는 `CONSENT_AND_DATA_USE_SPEC.md` §3~§5, 문서 실체는 `drafts/PIGOS_MASTER_TERMS_DRAFT.md`·`drafts/PIGOS_GLOBAL_PRIVACY_NOTICE_DRAFT.md`·`drafts/COUNTRY_ADDENDA/`. 결정 상태는 DECISION_REGISTER v1.1 (D-01~D-04 DECIDED).

## 1. 원칙

1. **문서 구조**: 모든 이용자에게 [마스터 약관 + 글로벌 개인정보 처리방침] 공통 1벌 + **거주/농장 소재 국가의 부속조항 1개**를 표시한다. 국가별 약관 전체 N벌을 만들지 않는다.
2. **법역 판별(jurisdiction resolution)**: IP는 참고값일 뿐 판별 기준이 아니다. 기준은 ① 가입 시 이용자가 선택한 국가 ② 농장 소재지 주소 (①② 불일치 시 보수적으로 더 엄격한 법역 적용 + [COUNSEL] 확인). 미국은 농장 소재 **주(state)** 코드까지 판별한다.
3. **버전 바인딩**: 표시된 모든 문서의 `notice_version`을 동의 시점에 consent_ledger에 기록한다 (CONSENT_SPEC §5). 문서 개정 시 재고지 규칙은 §6.
4. **언어**: 기본 표시 언어는 서비스 언어 설정을 따르되, 현지어 법정 요구 국가는 해당 현지어본을 **법적 우선본**으로 표시한다(§5). 번역본 미확정 국가는 해당 국가 출시 게이트 미해제로 취급.

## 3. 미국 주별 분기 (ADDENDUM_US 별표 연동)

원칙: **약관 문서는 전 주 공통 1벌**(ADDENDUM_US에 주별 별표 내장). 화면 동작만 주 코드로 분기한다.

| 주 코드 | 추가 동작 | 근거 |
|---|---|---|
| NE (네브래스카) | **농업데이터 판매 서면(전자) 옵트인 단계 추가** — 목적②(익명·집계 포함 판매)에 대해 별도 체크+전자서명 수준 기록. 미동의 시 NE 농장 데이터는 PigSignal 편입 제외 | LB525 (2026-07-17 발효) [근거: US_legal §7] |
| CA (캘리포니아) | "Do Not Sell or Share My Personal Information" 링크 상시 노출(footer+설정) / 수집 시점 고지(notice at collection) 배너 / GPC(Global Privacy Control) 신호 존중 | CCPA/CPRA (B2B 포함) |
| CO·CT 등 UOOM 주 | Universal Opt-Out Mechanism(GPC 등) 신호 수신 시 목적⑤·타겟광고 자동 OFF | 각 주법 (ADDENDUM_US 별표 M열) |
| MD (메릴랜드) | 민감정보(정밀 위치=농장 GPS 가능성) 판매 금지 — 목적⑤에서 위치 필드 제외 | MODPA [COUNSEL] |
| 기타 주 | 공통 플로우 (별표 고지로 커버) | — |

주 판별: 농장 주소의 주 코드. 복수 주에 농장 보유 시 **주별로 해당 농장 데이터에 각 주 규칙 적용** (계정 단위 아님 — NE 농장만 NE 옵트인 요구).

## 4. 화면 플로우 (가입)

```
[1] 국가 선택(기본: 추정값 프리필, 수정 가능)
    └ CN → 차단 화면. TH/VN → 게이트 상태 확인(미해제 시 무료 Core만 or 대기열)
[2] 문서 표시: 마스터 + 방침 + 해당 부속조항 (각각 개별 링크·스크롤 뷰, notice_version 표시)
[3] 필수 동의: 약관 동의 / 방침 확인 — 체크 2개 (묶음 금지)
[4] 목적② 고지 블록: 국가별 문구 (KR=익명처리·제외요청 안내 / EU·GB·BR=LI·이의권 안내 / US=비식별 고지)
    └ 토글 아님 (D-01). "자세히·제외 요청" 링크만
[5] 선택 토글: ③ AI 학습 / ④ 기업 연구 / ⑤ 리드 제공 — 기본 전부 OFF, 개별 토글 (D-02)
    └ VN: ⑤ 미노출 / US-NE: ②용 서면 옵트인 단계 삽입
[6] (해당 시) 광고 수신 동의(KR), 쿠키 배너(EU/GB)
[7] consent_ledger 기록: purpose_code × 상태 × notice_version × jurisdiction × 시각
```

설정 화면: [5]의 토글 + ② 제외 요청/이의권 + 문서 열람(현재 적용 버전·이력) + 철회 효과 고지(D-04 — 기제공 익명 산출물 존속 안내).

## 6. 개정·재고지 규칙

1. 일반 개정: 적용 7일 전 서비스 내 공지. 불리한 변경: 30일 전 공지 + 개별 통지(마스터 제3조).
2. **동의 범위가 넓어지는 변경(새 목적 추가 등)은 공지로 갈음 불가** — 해당 목적 옵트인 재수집 (KR_legal §8 재동의 경계선).
3. 개정 시 notice_version 증가 → 로그인 시 변경 요약 배너 → 필수 재동의 여부는 변경 성격에 따라 법무 판정 플래그.
4. 부속조항만의 개정은 해당 국가 이용자에게만 고지.
