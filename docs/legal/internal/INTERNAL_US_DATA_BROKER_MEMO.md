# INTERNAL — 미국 데이터 브로커 등록 해당성 메모 (US)

> **INTERNAL / DRAFT — 게시 금지(고객 배포 금지).** 본 문서는 고객용 부속조항(ADDENDUM_US)에서 분리한 사내 판단 메모이다. 데이터 브로커 등록법 해당성 평가·전략을 담으며, 고객 약관에는 결론만 반영하지 않고 본 메모에서 관리한다. 인용 §는 `docs/legal/research/US_legal.md`.

## 1. 대상 등록법 (2026-07 기준)

| 주 | 법 | 핵심 정의 | 등록비·의무(요약) |
|---|---|---|---|
| CA | Delete Act (SB 362) + SB 361 개정 | **직접 관계가 없는** 소비자의 개인정보를 수집·판매하는 사업자 | 연 $6,000, 1월 등록, DROP 삭제 플랫폼 연결(2026-08-01), 45일마다 삭제 처리, 위반 $200/일 |
| VT | 2019 등록법 | 직접 관계 없는 소비자 데이터 매매 | 연 $100, 1/31 |
| TX | SB 2105 (Bus.&Com. Code ch. 509) | 제3자 데이터 매매 | 연 $300 + 웹사이트 고지 |
| OR | HB 2052 | 제3자 데이터 매매 | 영업 전 등록, 미등록 $500/일 |
| CT | Public Act 26-64 | 제3자 데이터 매매 | $2,500, 2026-10-01 발효 |

[근거: US §3.3]

## 2. PigSignal 판단 프레임

1. 와이즈레이크는 농장(사용자)과 **직접 관계(direct relationship)** 가 있으므로, "직접 관계 없는 소비자 데이터"를 요구하는 CA 정의상 원칙적으로 데이터 브로커 비해당 가능성이 높다.
2. 판매 대상이 **진정한 de-identified·집계 데이터뿐이라면** "개인정보" 판매가 아니므로 이 점에서도 제외 논거가 성립한다.
3. 단, 잔존 리스크:
   - (a) 목적⑤ 리드 제공에서 **사용자 아닌 제3자(사용자가 입력한 거래처·수의사 연락처)** 정보를 판매하면 "직접 관계 없음" 요건이 충족되어 브로커 정의에 걸릴 수 있음. → **리드 제공 대상을 '본인이 옵트인한 사용자 본인 정보'로 한정**하면 리스크 대폭 축소(고객 약관 제1조2에 제3자 연락처 제외 반영).
   - (b) 주별 정의 차이(TX·OR·VT·CT의 '직접 관계' 문언이 CA와 상이).

## 3. 결론(초안)

현 설계(익명·집계 판매 + 본인 옵트인 리드)면 등록 의무 비해당 가능성이 높다. 단 주별 정의 차이로 잔존 불확실성이 있어 확정 전이다.

## 4. COUNSEL 질의

- [COUNSEL — US §8 Q5] PigSignal(익명·집계)과 목적⑤(옵트인 리드)가 CA·TX·OR·VT·CT 각 등록법상 "data broker" 정의에 해당하는지 — 특히 **TX ch.509의 광범위 정의**, 사용자 입력 제3자 연락처 취급.
- 등록 발생 시 운영 부담(DROP 연결·삭제 처리 SLA) 및 리드 상품 설계 조정 검토.
