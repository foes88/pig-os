# PigOS 약관·개인정보·DPA 벤치마크 종합 대조 (경쟁사/시장 관행 대비)

> **성격**: 경쟁사·시장 관행 대비 PigOS 초안(마스터 약관·글로벌 방침·B2B DPA)의 **대조 및 반영 권고**. 변호사 확정 전 **내부 검토자료**이며, 고객 게시본 아님.
> **저작권 원칙**: 경쟁사 문안 **복제 금지**. 아래 서술은 조항의 **접근법·구조·짧은 관찰**만 담으며, 인용은 접근방식 식별을 위한 최소 발췌(1문장 이하)에 그친다. 권고 문안은 경쟁사 문구가 아닌 our-voice 요약 방향으로만 제시한다.
> **한계**: 각 사의 **공개 게시문서 확인분**에 한정. "미확인"은 존재하지 않는다는 확정이 아니라 공개문서에서 노출되지 않았음을 의미한다. 벤치마크는 법적 안전의 보증이 아니며, 최종 문안은 변호사 확정을 요한다.
> 원자료: `RAW_NA.md`, `RAW_EU.md`, `RAW_LATAM_ASIA.md`, `RAW_DPA_OWNERSHIP.md`. 대조 대상 초안: `PIGOS_MASTER_TERMS_DRAFT.md`, `PIGOS_GLOBAL_PRIVACY_NOTICE_DRAFT.md`, `PIGOS_B2B_DPA_DRAFT.md`.

## 1. 쟁점별 시장 관행 대조표

열 정의: **[시장 대체적 관행]** = 다수 사업자가 채택하는 접근 / **[주목 선례]** = 누가 어떻게 했는지 특기점 / **[PigOS 현재 초안]** = 우리 문서 반영 상태 / **[갭·판정]** = 정합 / 부족 / 선진(시장보다 앞섬) / 차별화(시장 공백 선점).

### 1-1. 데이터 소유권

| 항목 | 내용 |
|---|---|
| 시장 대체적 관행 | 두 갈래 양극화. (a) "고객(생산자) 소유 + 회사 라이선스" 명문화(Ever.Ag "owned by you", FBN·Climate·AgriWebb, VN PigPro, CO PorciWeb) vs (b) 소유권 **아예 침묵**(PigCHAMP·MetaFarms·Herdwatch). 일부는 공급자 귀속(Agriness "수집 DB=자사 소유", Nedap "벤더 소유") 또는 소유 선언 회피·권한 프레이밍(John Deere). |
| 주목 선례 | Climate FieldView: "You own all Customer Farm Data"(§4.1) + 비독점·목적한정 라이선스. John Deere: 소유선언 자체를 회피하고 "permissions you set" 통제 프레이밍. Agriness(BR): 원장이 아닌 "수집으로 형성된 DB"를 자사 자산으로 명시. |
| PigOS 현재 초안 | 마스터 제9조①: "농장 데이터에 대한 권리는 회원에게 유보, 회사는 소유권 미취득" + 제9조②: 비독점·제한적 이용허락(제10조 목적 초과 불가). |
| 갭·판정 | **정합·선진**. Climate형 "고객 소유 + 목적한정 라이선스"를 이미 채택. 축산 전용 경쟁사 다수(PigCHAMP·MetaFarms·Herdwatch)가 소유권 침묵인 반면 PigOS는 명문화 → 차별화 여지. |

### 1-2. 집계·익명 데이터 상업화

| 항목 | 내용 |
|---|---|
| 시장 대체적 관행 | **광범위 활용이 표준**. "익명화하면 개인정보 아님 → 목적 제한 없이 활용"이 북미 지배 프레이밍(MetaFarms "any purpose", PigCHAMP "without limitation"). 핵심 기법은 집계·비식별물을 원 데이터 정의에서 **제외 → 회사 산출물로 재분류 → 상업화**(FBN·Climate). 단 노골적 "판매(sell)"는 대체로 회피, "연구·산업 파트너 제공/인사이트"로 프레이밍. |
| 주목 선례 | FBN: "we own ... aggregated and/or anonymized data, analytics, benchmarking" — 개별 데이터 판매금지 약속과 집계 상업화를 **모순 없이** 병립. Agriness(BR·LATAM 최대): 집계·익명 데이터를 "마케팅·데이터분석 전문업체와 공유"까지 정면 명문화 — LATAM 실제 선례. 유럽 5개사는 집계 상업화를 **거의 게시 안 함**(Pigax는 순수 processor로 2차활용 포기). |
| PigOS 현재 초안 | 마스터 제10조 목적②: 익명 통계 산출물의 PigSignal 제3자 제공(**유상 판매 포함** 명시). 제2조11호 "익명 통계 산출물" 정의(비가역 처리). 제10조⑥·방침 제3조④ 재식별 방지 조치. |
| 갭·판정 | **정합**. 집계 소유권 재분류는 시장 표준과 부합. 다만 PigOS는 "유상 판매 포함"을 **명시**해 시장의 판매 회피 관행보다 직접적 → 프레이밍 톤 검토 필요(제2 참조). 유럽에선 오히려 공격적 포지션 → LI·이의권 문서화로 방어. |

## 2. PigSignal(집계 상업화) 심층

### 2.1 농업 SaaS의 2단 구조 = PigSignal의 직접 선례

RAW_DPA_OWNERSHIP의 핵심 발견: 농업 SaaS 데이터 조항은 거의 예외 없이 **2단 구조**를 쓴다.

1. **개별 데이터(Customer/Farm Data)** → "농부가 소유(owns)" 선언 + 회사는 광범위 grant-back 라이선스
2. **집계·비식별 데이터** → 원 데이터 정의에서 **명시적 제외** → "회사가 소유(we own)" → 상업화 자유

즉 "farmer owns their data"는 **개별 식별 데이터에 한정된 선언**이고, 집계·비식별 파생물은 회사 자산으로 재분류해 상업화 근거를 만든다. FBN("we own ... aggregated and/or anonymized data")·Climate(§4.2 집계물을 Customer Farm Data 정의에서 제외)가 대표. **이 2단 구조가 PigSignal의 직접 선례**다.

PigOS 정합 상태: 마스터 제2조10호(농장 데이터)·11호(익명 통계 산출물)를 **분리 정의**하고, 제9조(농장 데이터 권리 유보)와 제10조 목적②(익명 통계 산출물의 PigSignal 상업화)를 구분한 것은 이 2단 구조에 **이미 부합**. 다만 "집계·비식별 산출물은 농장 데이터 정의에서 제외되어 회사가 소유하는 별개 산출물"이라는 **소유권 재분류의 명시성**은 제9조에서 더 강화 가능(권고 4-1 참조).

### 2.2 재식별 방지 수치 비교

| 기준 | PigCHAMP(공개 약관) | PigOS 내부표준 |
|---|---|---|
| 최소 집계 단위 | 최소 **3개 농장 시스템** | k=10 / k=20 (`ANONYMIZATION_AND_RELEASE_STANDARD`) |
| 단일 기여 상한 | 단일 농장 **60% 초과 금지** | 지배율 70% / 85% |
| 노출 위치 | **약관에 수치 명시**(신뢰 장치) | 내부표준 관리, 약관 비기재([D-05/D-06 OPEN]) |

관찰: PigOS 내부표준(k=10/20, 지배율 70/85)은 PigCHAMP(3개 시스템·60%)보다 **엄격**하다. 그러나 PigCHAMP는 이를 **약관에 노출해 신뢰 마케팅**으로 쓰는 반면 PigOS는 내부표준에만 둔다. → **일부 수치의 약관 노출**을 검토하면(예: "최소 코호트 규모·단일 기여도 상한을 적용하며 그 기준은 익명처리 기준 문서에 따른다"에 대표 수치 병기) 경쟁 우위. 단 수치 노출은 유연성을 희생하므로 사업·기술팀 판단 병행.

### 2.3 옵트아웃 취약 경쟁사 대비 차별화

| 사업자 | 집계 옵트아웃 | grant-back 라이선스 톤 |
|---|---|---|
| FBN | **없음**(집계 참여가 이용 조건) | "royalty-free, worldwide, irrevocable, perpetual ... commercially exploit" — 영구·무제한(공격적) |
| John Deere | **없음**(집계 옵트아웃 미명시) | 소유선언 회피·permission 프레이밍 |
| Climate | 계정 설정 공유 선호 관리(상대적 제공) | **목적-한정 라이선스**(서비스·내부운영·R&D), 투기목적 거래 자율 배제(§4.2) |
| **PigOS** | **제외 요청권 상시 보장**(목적②) + 목적③④⑤ 옵트인·기본 OFF | 제9조② **비독점·제한적**(제10조 목적 초과 불가) |

권고 방향(RAW_DPA_OWNERSHIP 시사점 5 반영):
- **Climate형 "목적-한정 라이선스"를 채택**하라 — PigOS 제9조②는 이미 목적한정. 유지·강화.
- **FBN형 "영구·무제한 grant-back"은 회피**하라 — "perpetual·irrevocable·commercially exploit" 류 문구는 규제·평판 리스크. PigOS 초안에 해당 문구 없음(양호).
- John Deere식 **소유선언 회피는 비권장** — 신뢰 저하 우려. PigOS는 제9조①에서 소유권 유보를 명시(양호).
- **집계 옵트아웃 실제 제공은 시장 대다수(FBN·John Deere)가 안 하는 차별화** — "farmer owns"를 라이선스 회수가 아닌 **실질 통제**로 구현. EU·한국·브라질 규제 방어력 + 신뢰 마케팅.

## 3. 업계 자율규범(Ag Data Transparent) 채택 권고

### 3.1 ADT란

미국 농업계가 2014년 합의한 "Privacy and Security Principles for Farm Data" 기반 **자율 인증 프로그램**. FBN·Climate·John Deere 등 주요 SaaS가 인증(Seal) 취득 → **사실상 산업 표준 프레임**. 2024 개정에서 **"AI/기계학습 학습 사용 여부 공개"**를 신규 원칙화.

ADT Core Principles(양돈 특화 관점 요약):
- **소유·통제**: 농가가 운영 데이터 소유, 이전은 계약 명시
- **수집·동의**: 데이터 카테고리별(축산 포함) 명시 동의
- **제3자 공유**: 접근 제3자군 정의(통합파트너·비즈니스파트너 등)
- **매각 시**: 통지 + **삭제 선택권**
- **선택**: 옵트인/아웃/비활성, 개별 선택
- **이동성**: 비집계 데이터 반출(익명·집계는 이동성 의무 없음)
- **AI/알고리즘**: **AI 학습 이용 여부 고지**(2024 신규)
- **익명화·집계**: 익명 데이터셋 포함 여부 고지 + **옵트아웃 제공 권고**

### 3.2 ADT 11문항 공시 템플릿 (양돈 특화)

ADT 인증은 표준 **11개 질문**에 yes/no + 근거문서 링크로 답하는 방식 — 사실상 농업 SaaS **공시 템플릿**. 이를 양돈 특화(개체·방역·도축 파트너)로 이식 권고:

| # | ADT 표준 문항 | 양돈 특화 공시 방향 |
|---|---|---|
| ① | 사업자 신원 | 와이즈레이크·PigOS 명시 |
| ② | 수집 데이터 종류 | 개체(모돈·자돈·웅돈)·생산기록·방역·이력추적 데이터 구분 |
| ③ | 소유권 명시 여부 | 농장 데이터=회원 유보 / 익명 산출물=회사(2단 구조) |
| ④ | **집계 옵트아웃 가능 여부** | **제공(제외 요청권)** — 시장 차별화 포인트 |
| ⑤ | 벤더(계약자) 준수 | 인테그레이터·계약농가 권한 보증(제4조·제9조) |
| ⑥ | 제3자 접근 전 동의 | 목적③④⑤ 옵트인·기본 OFF |
| ⑦ | **집계 데이터 판매 투명성** | 유상 제공(판매) 포함 명시(제10조②) |
| ⑧ | 이동성·삭제 | 반출(제9조⑥)·삭제(제16조) |
| ⑨ | 침해통지 | 마스터 제14조·방침 제12조·DPA 제6조 |
| ⑩ | 정책변경 통지 | 제3조 개정 절차 |
| ⑪ | 매각 시 데이터 처리 | 제18조·방침 제13조 영업양도 통지 |
| (추가) | **방역·이력추적 데이터의 정부 공유** | 가축전염병 신고 의무·당국 제공(제11조② 연계) |
| (추가) | **도축·유통 파트너 공유** | PigSignal 수신 기관·재식별 금지 계약 |

### 3.3 인증 마크의 B2B 신뢰 효과

ADT Seal은 실체 규제가 아닌 **투명성(공시) 규범**이나, 인증 마크가 **B2B 신뢰 장치**로 기능한다. FBN·Climate·John Deere가 취득해 신뢰 마케팅에 활용. PigOS가 ADT 11문항 공시표를 `TERMS_DISPLAY_SPEC`/국가별 부속에 이식하고 (가능 시) 인증을 취득하면, 북미 B2B 조달·파트너 신뢰에서 우위. 최소한 **11문항 공시표 자체를 our-voice로 채택**하는 것을 권고.

## 5. PigOS 차별화·세일즈 포인트

시장 공백을 PigOS가 선점하는 지점 (B2B/글로벌 세일즈 논거):

1. **진짜 DPA를 갖춘 축산 SaaS** — FBN·Climate·John Deere 등 미국 선도사조차 GDPR식 독립 DPA·subprocessor 목록·SCC가 부재. PigOS는 AgriWebb 수준의 **마스터 + B2B DPA + subprocessor + 국가부속** 다문서 확보 → EU·GB·글로벌 B2B(도축·유통·금융 파트너) 조달 심사 통과력이 곧 세일즈.

2. **집계 옵트아웃을 실제로 제공** — 업계 다수(FBN·John Deere)는 집계 옵트아웃 미제공, ADT조차 공시만 요구. PigOS는 **제외 요청권 상시 + 목적③④⑤ 옵트인·기본 OFF**로 "농가 소유"를 실질 통제로 구현. 규제 방어 + 신뢰 마케팅.

3. **AI·수의 면책 선제 도입** — 경쟁사 약관 대부분 AI 조항 부재(Herdwatch만 예외). PigOS는 수의 진단 대체 아님·긴급모니터링 아님·자동화 의사결정 부정을 상세 명문화 → ADT 2024 방향 선점.

4. **EU 대리인(Art.27) 실지정** — Breedr·Herdwatch 역외 구조가 대리인 공백을 노출하는 시장에서, 한국 사업자 PigOS가 실제 지정·기재하면 즉시 규제 우위.

5. **재식별 방지 수치 명문화 기반** — PigCHAMP만 유일하게 약관에 수치 노출. PigOS 내부표준(k=10/20·지배율 70/85)은 더 엄격 → 일부 노출 시 신뢰 장치화 가능.

6. **인테그레이터-계약농가 귀속 조항** — 어느 벤치마크도 다루지 않는 **시장 유일** 명문화. 계약농가 권한 보증·대리 동의 요건·귀속 분쟁 격리(제20조) → TH·VN·BR 통합모델 시장에서 결정적 차별화.

7. **국외이전 투명성** — EEA 완결로 회피하는 유럽 관행과 달리, PigOS는 한국 서버의 적정성 근거를 노티스에 전면 노출(Pigax 수준 이상 투명).

## 6. 주의·미확인

- **공개문서 미노출로 확인 못 한 것**: 中 수직계열(牧原·温氏)은 대외 SaaS 약관 미게시로 벤치마크 불가 — CN은 农信互联가 유일 대표. 일부 EU/ES(Porcitec·Agritec) 및 Granular/Corteva 상세, Cropin·Trimble·(일부)Breedr Terms 본문은 미확보. 韓 직접경쟁(팜스플랜·이지팜) 조항 본문 미추출.
- **벤치마크의 성격**: 시장 관행 스냅샷일 뿐 **법적 안전의 보증이 아님**. 경쟁사가 하고 있다는 사실이 적법성을 담보하지 않으며(Herdwatch의 US 관할 선택 등 반면교사 존재), 각국 강행법규 적용은 별개.
- **재식별 완전배제 불가**: 익명처리는 "합리적으로 재식별 불가" 수준이며 절대적 배제가 아님. 구 방침의 자인성 문구는 삭제됐으나, 재식별 리스크의 상시 재평가(제10조⑥) 유지 필요.
- **최종 문안은 변호사**: 모든 [D-xx]·[OPEN]·[COUNSEL] 태그 및 부표 placeholder는 변호사 확정·운영 실측(V프로세스) 후 확정. 본 대조표는 검토 입력물이지 확정 지시가 아님.
