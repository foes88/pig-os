## 한눈에 — 남은 것 우선순위
| 순위 | 미구현 기능 | 가치 | 비고 |
|------|-----------|------|------|
| **1** | 일일 사육현황 리포트 | 높음 | **지금 개발 중** |
| **2** | 백신 기록 | 높음 | 신규 모델 |
| **3** | 관리목표 진행률 | 중상 | config+snapshot 조합 |
| **4** | 모돈카드 v2 타임라인 | 중 | UI만 (API 있음) |
| **5** | LOSS_CALC 경제성 | 중상 | Phase 2 / Addon |
| **6** | 생시체중 필드+검증 | 중 | 146지표 다수 해소 |
| 후 | IOT·QR·거래현황·다중농장 | 낮음 | Addon/Phase 5+ |

> **요약**: 기록·검증·핵심보고서는 거의 다 됨. 남은 건 ①일일보고(진행중) ②백신 ③관리목표 ④모돈카드v2 정도가 "코어 마무리"이고, LOSS_CALC·IOT·QR은 차별화/Phase2.
