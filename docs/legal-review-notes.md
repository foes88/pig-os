# PigOS 법무 문서 검토 노트 (이용약관 / 개인정보보호)

> 작성 2026-06-15 · 야간스프린트 N6 · **변호사 검토 전 초안**
> 본 문서와 `/legal` 페이지 콘텐츠는 법적 효력을 갖지 않으며, 외부 법률 자문으로 확정해야 함.

## 1. 이번에 보강한 조항

### 이용약관(terms) — 4개 → 10개 조항으로 확장
1. 목적 (초안 고지 명시)
2. 정의 — Service / Member / Farm Data / Add-on
3. 계정 및 권한 — 농장 멤버십, 역할 기반 접근(Owner/Manager/Worker/Viewer), farm_id 테넌트 격리, 인증정보 책임
4. 요금제·무료 서비스·애드온·과금 — 핵심 무료, AI Insight 등 유료 구독, 세금 별도, 변경 사전 고지
5. 데이터 소유권 vs 사용권 — 회원 소유 + 회사에 제한적 처리 라이선스
6. 데이터 수익화·익명화·농가 배분 — 익명·집계 데이터 상품, '데이터 배당', 식별정보 사전 제거
7. 금지행위 — 불법 이용/허위 데이터/권리침해/역설계/타 테넌트 무단접근
8. 면책 및 책임 제한 — as-is, AI Insight 자문 아님, 묵시보증 부인, 강행 소비자보호 유지
9. 준거법 및 분쟁 해결 — 회사 주사업장 법/관할 + 거주국 강행법 예외
10. 해지·데이터 반출·변경 — 반출 후 삭제, 법정 보관 예외, 중요변경 사전 고지

### 개인정보보호(privacy) — 4개 → 10개 섹션으로 확장
수집 항목 / 수집 방법 / 이용 목적 / 제3자 제공·국외이전 / 보관·파기 / 이용자 권리(열람·정정·삭제·이동) / 쿠키·분석 / 보안조치(전송암호화·접근제어·감사로그·k익명성 k≥10) / 아동 / 책임 연락처(privacy@pigos.io) + 지역별(GDPR·CCPA/CPRA·PIPA) 요약.

## 2. 변호사 확정 필요 항목 (Must review)
- **준거법·관할(제9조)**: "회사 주사업장" 추상 표현 → 실제 설립지(예: 대한민국/와이즈레이크) 및 전속 관할 법원 확정 필요.
- **데이터 배당(제6조)**: '데이터 배당' 약속의 법적 구속력·산정식·지급조건 미정 → 마케팅 표현 vs 계약상 의무 경계 검토. 과대광고/소비자기만 리스크.
- **데이터 수익화 동의 근거**: 익명화 전 원본 처리의 적법근거(동의 vs 정당한 이익) 및 옵트아웃 제공 여부 확정.
- **AI Insight 면책(제8조)**: 수의·진단 자문이 아님을 명확히 했으나, 오류로 인한 손해 책임범위·보증 한도 수치화 필요.
- **책임 제한 상한**: 금액/기간 상한 구체화(예: 직전 12개월 결제액) 검토.
- **국외 이전(privacy 4)**: 실제 사용하는 클라우드 리전·하위처리자(서울 ap-northeast-2 등) 목록화 + SCC/적정성결정 근거 명시.
- **회사명/연락처**: 'WiseLake' 영문/국문 정식 상호, 사업자 정보, 개인정보 보호책임자(DPO) 지정 확정.

## 3. 지역별 추가 검토 포인트 (5개 시장)
- **KR (PIPA)**: 개인정보 처리방침 의무기재사항(처리목적·항목·보유기간·제3자·위탁·국외이전·권리·DPO) 형식 정합, 만 14세 미만 법정대리인 동의 규정.
- **EU/EEA (GDPR)**: 처리 적법근거 6조, 정보주체 권리(삭제·이동·반대), DPA(처리자 계약), 국외이전 SCC, 필요 시 DPO/대리인.
- **US-California (CCPA/CPRA)**: "Do Not Sell/Share" 고지(데이터 수익화와 직접 연관 — 중요), 민감정보 옵트아웃, 12개월 공개의무.
- **CN**: PIPL 별도 검토 필요(국외이전 보안평가·표준계약, 현지 저장 요건) — 현재 초안 미반영, 중국 진출 시 전용 조항 필수.
- **SEA/LatAm (VN/베트남·중남미)**: 베트남 PDPD, 브라질 LGPD 등 시장별 별도 검토. 현재 vi/es 번역은 UI 표기용이며 관할 법령 반영은 아님.
