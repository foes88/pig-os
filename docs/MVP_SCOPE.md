## MVP 한 줄 정의

**P0만 구현한다. P0는 제품의 뼈대다.**

전입 → 교배 → 분만 → 포유폐사 → 양자 → 이유 → 도폐사

이 흐름이 정확하면 모돈 상태·산차·포유두수·이유두수·번식 KPI가 깨지지 않는다.

## MVP 구현 범위

### 필수 입력 (구현)

| 기능 | 상태 |
|------|------|
| 모돈 전입 | 구현 |
| 교배 | 구현 |
| 분만 | 구현 |
| 포유자돈 폐사 | 구현 |

| 이유 | 구현 |

| 비육돈 입식/폐사/출하 | 구현 |

### 필수 검증 (구현)

| 검증 항목 | 구현 |
|----------|------|
| 날짜 순서 (전입→교배→분만→이유 순) | 구현 |
| 모돈 상태 전이 (상태 FSM) | 구현 |
| 이유두수 공식 (weaned = nursing_head - deaths - out + in) | 구현 |
| 분만 두수 공식 (total_born = BA + SB + MUM) | 구현 |
| nursing_head 자동계산 | 구현 |
| 산차 자동계산 | 구현 |
| 양자 거울 레코드 자동생성 | 구현 |
| 포유 중 도태/판매 차단 | 구현 |
| 도폐사 후 이벤트 차단 (exit_date) | 구현 |
| 월마감 잠금 (period_lock) | 구현 |
| 백엔드 검증 + 프론트 Zod schema 동기화 | 구현 |

### 필수 보고서 (구현)

| 보고서 | 핵심 내용 |
|--------|---------|
| 1. 모돈 현재 상태표 | 전체 모돈 상태별 두수/리스트 (GILT/PREGNANT/LACTATING/OPEN/ACCIDENT) |
| 2. 번식 성적 요약 | 교배·임신·분만·이유 사이클 흐름, WCI·NSY·PSY KPI |
| 3. 분만·포유·이유 성적표 | 총산·실산·이유두수·이유일령 성적 |
| 4. 도폐사/포유폐사 리포트 | 손실 원인별 두수, 기간별 폐사율 |
| 5. 데이터 오류/누락 리포트 | 날짜 역전, 두수 불일치, 상태 오류, 입력 누락 |

## MVP 제외 범위

### 제외 기능 (v1.1 이후)

| 기능 | 제외 이유 |
|------|----------|
| **부분이유** | nursing_head 연동 복잡 → MVP 숨김 처리. 지원 결정 시 반드시 검증 구현 필수 |
| 초발정 기록 | 번식 데이터 정합성에 영향 없음 |
| 모돈 장소이동 | 핵심 번식 사이클과 무관 |
| 모돈 그룹관리 | 편의 기능 |
| 모돈 농장이동 | 멀티팜 구조 결정 후 |
| 사료급이기록 | 사료 모듈 미포함 |
| 백신기록 | 건강관리 모듈 미포함 |
| 등지방 관리 | 고도화 분석 기능 |
| 일괄작업 / Excel 업로드 | 운영 편의 기능 |

### 제외 보고서 (v1.1 이후)

| 보고서 | 제외 이유 |
|--------|----------|
| 사료 급이 보고서 | 사료 기능 없으면 데이터 없음 |
| 백신/치료 보고서 | 건강관리 모듈 미포함 |
| 등지방/BCS 보고서 | 고도화 분석용 |
| 그룹별 성적 보고서 | 그룹관리 기능 확정 후 |
| 농장 간 이동 보고서 | 멀티팜 확정 후 |
| 일괄작업 이력 보고서 | 운영자 기능 |
