## 1. 플랫폼  [확정]
- **Web + Android**(모바일 우선, 오프라인 기록 후 동기화). Android = Google Play 출시(`io.pigos.app`).
- iOS = 개발 중(미출시). "coming soon"으로만.

## 2. 지원 언어  [확정]
- **8개 언어**: English, 한국어, 中文, Español, Tiếng Việt, ภาษาไทย, Português, Русский.
- (코드 근거: `src/messages/{en,ko,zh,es,vi,th,pt,ru}.json`, `i18n.test.ts`가 키 파리티 강제.)

## 3. 대상 시장  [확정-포지셔닝]
- **5개 글로벌 시장**: US · CN · SEA · LatAm · KR. (로그인 화면 문구 = "5 global markets · 8 languages".)

## 4. 무료 범위 (Core)  [확정]
- **무료·카드 불필요**: 농장 기록(모돈/웅돈/자돈/비육), **KPI 대시보드**(PSY·NPD·분만율·산자수·이유두수·FCR 등), **국가별 벤치마크**.
- 가입 없이 쓰는 **농장 건강 스코어카드**(공개 리드퍼널, `/scorecard`) — 국가 선택 + KPI 입력 시 밴딩·개선 포인트 제시.

## 5. AI 기능 (Addon, 선불 크레딧)  [베타/검증중]
- **AI Insight / 자연어 어드바이저**: 룰엔진 검증 결과를 자연어로 설명(판단은 룰엔진, LLM은 표현만).
- 성격: 운영자 판단 **보조(AI-assisted)** — 자동 진단·예측 아님.
- **주의**: 앱 Addon Store의 AI Insight는 현재 **버튼 비활성화(미연동)** 상태. 랜딩에서 "지금 바로 쓸 수 있다"고 단정하지 말 것 → "beta · 파일럿 파트너와 검증 중"으로 hedge(FACTS §5·§6과 일치).

## 6. 고객지원 (CS)  [확정-백엔드, 연동은 설정 시]
- 앱 내 1:1 문의(문의함 — 목록/작성/스레드). 다국어.
- QBridge CRM 양방향 연동 가능(문의 인입 + 답변 수신, 자동 다국어 번역) — env 설정 시 동작. 랜딩엔 "다국어 고객지원" 수준까지만.

## 7. 데이터 정책  [확정]
- 개별 농장 데이터는 식별가능 형태로 판매/공유 안 함. 익명·집계 사용은 옵트인 시에만. (`https://pigos.io/privacy`)
