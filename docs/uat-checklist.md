# PigOS UAT 체크리스트 (사람 검수 — 웹 실스택)

> 브라우저로 직접 클릭하며 전수 점검. 자동화(E2E)가 못 잡는 미관·카피·흐름까지 사람 눈으로.
> 대상: 웹 `localhost:3000` + API + DB(로컬). 계정: **e2e@pigos.io / e2e!2026pw**(전용 시드, `scripts/seed_e2e.py`).
> 작성: 2026-06-18. 각 항목 [통과/버그/미관]으로 표기하고 버그는 스샷+재현경로 남길 것.

## 0. 준비
- [ ] DB·API·웹 기동 (`docker compose up -d postgres redis` / `cd api && uv run uvicorn app.main:app` / `cd src && npm run dev`)
- [ ] 시드: `cd api && PYTHONPATH=. uv run python scripts/seed_e2e.py`
- [ ] 웹 `NEXT_PUBLIC_API_URL`이 그 API를 가리키는지(.env.local)

## 1. 인증/온보딩
- [ ] 로그인(이메일/비번) 성공 → 대시보드
- [ ] 아이디 저장 체크 → 로그아웃 후 재방문 시 이메일 프리필
- [ ] 언어 전환(ko/en/zh/es/vi) → **메뉴+내용 모두** 해당 언어, 원시 키(`nav.x`) 노출 0
- [ ] 잘못된 비번 → 에러 메시지(해당 언어), 401 처리
- [ ] 회원가입/온보딩 흐름(신규 농장 생성)

## 2. 돈군 CRUD
- [ ] 모돈 **등록**(귀표/품종/RFID) → 목록 즉시 반영
- [ ] 모돈 **검색**(귀표 부분일치) + 상태 필터
- [ ] 모돈 **수정**(귀표/품종) 저장 → 반영
- [ ] 모돈 **도폐사/판매**(사유 9종, 판매 시 체중/가격) → 상태 종료 전이 + 목록서 제외
- [ ] 모돈 상세: 번식 이력 타임라인 + 산차별 성적
- [ ] 웅돈 등록/수정 · 자돈 그룹 등록/폐사/이동 · 비육돈 그룹 등록/수정/출하

## 3. 번식 이벤트 (기록 입력 — 핵심)
- [ ] 모돈 선택 → 교배 입력(웅돈 1~3, 방식 AI/자연) → 저장 → **insights 배너**(정상/경고/심각)
- [ ] 분만 입력: **숫자 타이핑** 됨(+/- 아님) · 총산>35 등 검증 422 메시지 · born_alive 자동계산
- [ ] 이유 입력: 이유두수 공식(포유두수-폐사) 검증
- [ ] 사고(RTS/유산 등) · 자돈 폐사
- [ ] 최근 이벤트 이력에서 **수정**(pre-fill) · **삭제**(상태 롤백 경고) → 모돈 상태 되돌아감
- [ ] 월마감 잠금 기간 수정 시 423

## 4. KPI / 보고서
- [ ] 대시보드 KPI 카드(PSY/NPD/FR) + 관리대상 수 + 도태권고 badge
- [ ] 보고서 > 생산성적: 기간 선택, **품종별 토글**(group_by=breed), 국가 기준 대비 색상
- [ ] 보고서 > 비육성적(ADG/FCR/폐사율)
- [ ] 통합표(production-summary) 국가 기준값 동봉 표시
- [ ] CSV 내보내기 — 파일 열림, 값 일치
- [ ] PRRS 유전 · 모돈 보고서

## 5. 할 일·알림 (통합 2탭)
- [ ] '알림' 메뉴 1개 → 화면 안 **탭2**(관리대상/시스템알림)
- [ ] 관리대상: 과기한 6유형 + 도태권고, 액션버튼(교배/이유 입력으로 이동)
- [ ] 시스템알림: 개별 읽음/전체 읽음, 유형 필터
- [ ] 사이드바 '알림' 통합 배지 = 관리대상+미읽음
- [ ] 오늘 할 일: 목록, 완료/무시/담당자 배정

## 6. 설정/권한/기타
- [ ] 농장 설정(임신/포유/WSI/초교배일령) 저장 → 알림 기준 즉시 변경
- [ ] 임계값(thresholds) override 입력/삭제 → 국가/글로벌 복귀
- [ ] 팀원 추가/역할 변경(OWNER/MANAGER/WORKER/VIEWER) → VIEWER는 쓰기 막힘(403)
- [ ] 언어×국가 분리(언어 한국어인데 country US면 단위/통화 US) — config 따름
- [ ] Ask AI(챗) 질의 → Rule-grounded 응답

## 7. 모바일 웹/반응형·미관
- [ ] md 이하: 사이드바→하단탭, 기록입력 스택 레이아웃
- [ ] **이모지 잔존 0**(아이콘 벡터), 색·여백·카피 어색함 점검
- [ ] 빈 상태/로딩/에러 상태 문구(해당 언어)

## 8. 콘솔/네트워크
- [ ] 주요 화면 순회 시 콘솔 에러 0, 4xx/5xx 비정상 응답 0
- [ ] 새로고침/뒤로가기 시 상태 유지(인증/언어/필터)
