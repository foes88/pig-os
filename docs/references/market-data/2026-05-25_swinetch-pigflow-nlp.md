## PigOS vs PigFlow 경쟁 분석

| 항목 | PigFlow | PigOS |
|------|---------|-------|
| **자연어 인터페이스** | ✅ 출시 완료 | 🔧 Rule Engine 기반 Q&A 구현됨, LLM 연동은 Addon #1 |
| **시장** | 미국 중심 | 미국 + SEA + LatAm + KR (글로벌) |
| **진입 전략** | 유료 | Farm OS 무료 진입 + AI 어드바이저 유료 업셀 |
| **AI 기능** | 자연어 조회 | Loss Detection + Anomaly Detection + 예측 (예정) |
| **하드웨어 연동** | Jyga 통합 | 벤더 중립 (특정 하드웨어 종속 없음) |
| **오프라인** | 불명확 | WatermelonDB 오프라인 동기화 지원 |

## PigOS 대응 전략

1. **Rule Engine Q&A 조기 고도화** — 현재 Template Renderer → LLM Addon 전환 시점 앞당기기 검토
2. **차별화 포인트 명확화** — 글로벌 다국어 + 오프라인 + 무료 진입점 (PigFlow는 미국 유료 중심)
3. **PigFlow 기능 지속 모니터링** — 자연어 질의 범위, 통합 파트너 추가 여부
