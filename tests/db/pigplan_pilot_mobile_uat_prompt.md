# 모바일 UAT 프롬프트 — 피그플랜 파일럿 데이터 (4농장)

> 테스터/모바일 개발자에게 전달. 네이티브 앱(Android: Kotlin+Compose / iOS: Swift+SwiftUI)으로
> 파일럿 계정 로그인 → 역할별 데이터·RBAC·오프라인 검증.

---

## ⚠️ 0. 접속 대상 결정 (선행 필수)

파일럿 계정·데이터는 **로컬 Docker `pigos` DB**에 있습니다. 앱 릴리스 빌드는 `api.pigos.io`(운영)를 봅니다.
둘 중 하나를 정하세요:

- **(A) 권장 — 개발빌드 → 로컬 API**: PC에서 `cd api && uv run uvicorn app.main:app --host 0.0.0.0 --port 8000` 기동 후,
  같은 WiFi의 폰이 `http://<PC_LAN_IP>:8000/api/v1` 을 보도록 앱 API base 설정(디버그 빌드 환경변수/설정화면).
  방화벽 8000 허용 필요. **운영 데이터 오염 없음.**
- (B) 스테이징/운영에 파일럿 적재: `api.pigos.io`로 보게 하려면 파일럿 데이터·계정을 그쪽 DB에 이관해야 함
  (운영에 테스트 데이터 유입 → 비권장, 별도 승인 필요).

> 아래 시나리오는 (A) 기준. base URL만 (B)로 바꾸면 동일.

## 3. 역할별 테스트 시나리오

### A. FARM_OWNER (예: owner_2807)
1. **로그인** → 홈(대시보드) 진입. 상단 농장명 "용암축산".
2. **대시보드**: 활성모돈수 ≈ 349, KPI 카드(PSY/NPD/수태율) 값 표시(0/빈값 아님).
3. **모돈 목록**: 스크롤·검색·상태 필터(임신/포유/공태/후보/사고). 상세 진입 → 번식이력 타임라인.
4. **기록 입력**: 교배→분만→이유 탭 전환. 실제로 1건 입력(오프라인 테스트 겸).
5. **리포트**: 번식성적 월별 표 렌더, 기간 변경, CSV(있으면).
6. **알림**: 과기한 모돈 목록(≈779건), 유형별 필터, 항목→모돈 상세 이동.
7. **RBAC**: 타 농장 데이터 접근 수단이 UI에 없어야 함(농장 전환기 미노출).

### B. DEALER_ADMIN (예: dealer_east)
1. 로그인 → **농장 전환기에 2개(2807, 4448)만** 표시.
2. 두 농장 각각 대시보드/리포트 열람, 값이 앵커와 일치.
3. 848/978은 **목록에 없어야** 함(격리).

### C. VENDOR_ADMIN
1. 로그인 → **농장 전환기 4개 전부**.
2. 각 농장 순회하며 데이터 로드 정상.

## 4. 모바일 특화 테스트 (핵심)

1. **오프라인 입력·동기화**: 비행기모드 → 교배/분만/이유 입력 → 온라인 복귀 → 자동 동기화, 서버 반영 확인(중복/유실 없음).
2. **언어 전환**: 설정에서 en/zh/es/vi/th/pt/ru 전환 → 라벨·상태용어·숫자 포맷 정상. (ko는 관리자 전용)
3. **저사양/네트워크 열악**: 3G/약한 신호에서 목록 로딩·재시도·타임아웃 처리.
4. **큰 데이터셋**: 978(활성 982두)에서 모돈 목록 스크롤 성능·페이지네이션.
5. **카메라/푸시**(구현 시): 사진 첨부, 알림 수신 → 딥링크 진입.
6. **세션/보안**: 토큰 만료 후 재로그인 흐름, 로그아웃 시 로컬 데이터 정리.
