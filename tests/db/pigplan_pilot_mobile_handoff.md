## 검증 시나리오 (모바일)
1. **로그인**: 7계정 각각 로그인 → 역할별 농장 가시성(vendor 4 / dealer 2 / owner 1) 정확.
2. **대시보드**: 활성모돈수가 위 앵커와 일치. KPI 카드(PSY/NPD/수태율) 값 표시(빈값 아님).
3. **모돈 목록**: 스크롤·검색·상태필터(임신/포유/공태/후보/사고). 상세 → 번식이력 타임라인.
4. **리포트**: 번식성적 월별 표 렌더, 기간 변경.
5. **알림**: 과기한 목록(앵커 건수), 유형 필터.
6. **RBAC 격리**: owner가 타 농장 접근 수단 없음(전환기 미노출). dealer는 2농장만.
7. **모바일 특화**: 오프라인 입력→온라인 복귀 동기화(무손실), 언어 전환(en/zh/es/vi/th/pt/ru), 큰목록(978 982두) 스크롤 성능.

## (PC 담당) 접속 안 될 때
1. API 기동: `cd c:/dev/PigOS && docker compose up -d postgres redis api` → `http://localhost:8000/health` 확인.
2. 방화벽(관리자 PowerShell): `New-NetFirewallRule -DisplayName "PigOS API 8000" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow`
3. PC IP 재확인: `ipconfig` → WiFi 어댑터 IPv4 (예: 192.168.3.46). 바뀌면 위 Base URL 갱신.
